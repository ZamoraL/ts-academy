Un **closure** es una función que **recuerda las variables** del lugar donde fue creada, incluso después de que ese lugar terminó de ejecutarse.

## Ejemplo

```js
function crearContador() {
  let cuenta = 0
  return function () {
    cuenta++
    return cuenta
  }
}

const contar = crearContador()
contar() // 1
contar() // 2
contar() // 3
```

`crearContador` ya terminó, pero la función devuelta sigue teniendo acceso a `cuenta`. Cada llamada a `crearContador()` crea un `cuenta` **nuevo e independiente**:

```js
const otro = crearContador()
otro()   // 1
contar() // 4
```

## Para qué sirven

### Estado privado

Nadie desde fuera puede tocar `cuenta` directamente:

```js
function crearCuenta(saldoInicial) {
  let saldo = saldoInicial
  return {
    depositar: (m) => { saldo += m },
    consultar: () => saldo,
  }
}
```

### Fábricas de funciones

```js
const multiplicarPor = (factor) => (n) => n * factor
const doble = multiplicarPor(2)
const triple = multiplicarPor(3)
doble(5)  // 10
triple(5) // 15
```

### Callbacks que recuerdan datos

```js
function crearSaludo(nombre) {
  return () => console.log(`Hola, ${nombre}`)
}
setTimeout(crearSaludo('Ada'), 1000)
```

## Closures en React

Cada render de un componente crea funciones nuevas que "capturan" los valores de ese render. Entender closures te ahorrará muchos bugs con `useState` y `useEffect`.

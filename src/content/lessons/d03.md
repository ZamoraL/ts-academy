## El operador in

`'propiedad' in objeto` comprueba si el objeto tiene esa propiedad. TS lo usa para distinguir tipos de objeto:

```ts
type Pez = { nadar: () => void }
type Ave = { volar: () => void }

function mover(animal: Pez | Ave) {
  if ('nadar' in animal) {
    return animal.nadar() // animal: Pez
  }
  return animal.volar()   // animal: Ave
}
```

Si un tipo tiene la propiedad como **opcional**, aparece en ambas ramas:

```ts
type Humano = { nadar?: () => void; volar?: () => void }

function mover(animal: Pez | Ave | Humano) {
  if ('nadar' in animal) {
    animal // Pez | Humano
  } else {
    animal // Ave | Humano
  }
}
```

## instanceof

Para **clases** (y cualquier cosa con `prototype`), usa `instanceof`:

```ts
function registrar(x: Date | string) {
  if (x instanceof Date) {
    console.log(x.toUTCString()) // x: Date
  } else {
    console.log(x.toUpperCase()) // x: string
  }
}
```

Muy común con errores:

```ts
try {
  // ...
} catch (e) {
  if (e instanceof TypeError) { ... }
  else if (e instanceof Error) { console.log(e.message) }
}
```

## ¿Cuál uso?

| Para distinguir... | Usa |
|---|---|
| Primitivos | `typeof` |
| Instancias de clases (Date, Error, Map, tus clases) | `instanceof` |
| Objetos planos con propiedades distintas | `in` |
| Arrays | `Array.isArray` |
| Objetos con una propiedad "etiqueta" | discriminated unions (unidad 6) |

## Limitación de instanceof

Solo funciona con valores creados con `new`. Los objetos que vienen de JSON son objetos planos, aunque tengan la misma forma:

```ts
class Usuario { constructor(public nombre: string) {} }
const u = JSON.parse('{"nombre":"Ada"}')
u instanceof Usuario // false
```

Para datos externos, usa `in`, `typeof` o una propiedad discriminante.

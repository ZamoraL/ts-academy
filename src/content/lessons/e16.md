Utility types para **extraer** tipos de funciones y promesas.

## ReturnType\<F>

El tipo que devuelve una función:

```ts
function crearSesion(usuario: string) {
  return { usuario, token: crypto.randomUUID(), expira: Date.now() + 3600_000 }
}

type Sesion = ReturnType<typeof crearSesion>
// { usuario: string; token: string; expira: number }
```

Recuerda el `typeof`: `ReturnType` necesita un **tipo** de función.

## Parameters\<F>

Los parámetros como **tupla**:

```ts
function log(nivel: 'info' | 'error', mensaje: string, datos?: object) {}

type P = Parameters<typeof log>
// [nivel: 'info' | 'error', mensaje: string, datos?: object]

type Nivel = Parameters<typeof log>[0] // 'info' | 'error'
```

### Envolver funciones

Con genéricos, sirve para crear "decoradores" que conservan la firma exacta:

```ts
function conLog<F extends (...args: any[]) => any>(fn: F) {
  return (...args: Parameters<F>): ReturnType<F> => {
    console.log('llamando con', args)
    return fn(...args)
  }
}

const sumarLog = conLog((a: number, b: number) => a + b)
sumarLog(1, 2)   // ✓ number
sumarLog('1', 2) // Error
```

## Awaited\<T>

Desenvuelve promesas (incluso anidadas):

```ts
type A = Awaited<Promise<string>>          // string
type B = Awaited<Promise<Promise<number>>> // number
type C = Awaited<boolean>                  // boolean
```

Combinado con `ReturnType`, obtienes el resultado real de una función async:

```ts
async function cargarPerfil(id: number) {
  const r = await fetch(`/api/perfil/${id}`)
  return (await r.json()) as { nombre: string; avatar: string }
}

type Perfil = Awaited<ReturnType<typeof cargarPerfil>>
// { nombre: string; avatar: string }
```

## Otros

```ts
class Punto { constructor(public x: number, public y: number) {} }

type Args = ConstructorParameters<typeof Punto> // [x: number, y: number]
type Inst = InstanceType<typeof Punto>          // Punto
```

## Cuándo usarlos

Cuando el tipo **ya existe** implícitamente en el código (lo que devuelve una función de una librería, los parámetros de un callback) y quieres reutilizarlo en lugar de copiarlo a mano. Si la función cambia, el tipo derivado cambia con ella.

Los bucles repiten código.

## for

```js
for (let i = 0; i < 5; i++) {
  console.log(i) // 0, 1, 2, 3, 4
}
```

Tres partes separadas por `;`:

1. **Inicio**: `let i = 0`, se ejecuta una vez.
2. **Condición**: `i < 5`, se comprueba antes de cada vuelta.
3. **Paso**: `i++`, se ejecuta al final de cada vuelta.

## Acumular

Patrón muy común: una variable fuera del bucle que se va actualizando.

```js
let suma = 0
for (let i = 1; i <= 10; i++) {
  suma += i
}
console.log(suma) // 55
```

## while

Repite **mientras** la condición sea verdadera. Útil cuando no sabes cuántas vueltas habrá:

```js
let n = 1
while (n < 100) {
  n *= 2
}
console.log(n) // 128
```

Si la condición nunca se vuelve `false`, tienes un **bucle infinito**. En esta app, el código se detiene a los 3 segundos.

## break y continue

```js
for (let i = 0; i < 10; i++) {
  if (i === 3) continue // salta a la siguiente vuelta
  if (i === 6) break    // sale del bucle
  console.log(i)        // 0, 1, 2, 4, 5
}
```

## Recorrer un string

```js
const palabra = 'hola'
for (let i = 0; i < palabra.length; i++) {
  console.log(palabra[i])
}
```

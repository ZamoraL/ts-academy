Los mismos tres puntos `...` hacen dos cosas opuestas según dónde los pongas.

## Spread: expandir

Copia los elementos de un array o las propiedades de un objeto **dentro de otro**.

### Arrays

```js
const a = [1, 2]
const b = [3, 4]
const todos = [...a, ...b]   // [1, 2, 3, 4]
const copia = [...a]         // copia (superficial)
const conNuevo = [...a, 99]  // [1, 2, 99], sin modificar a
```

### Objetos

```js
const base = { color: 'rojo', talla: 'M' }
const camiseta = { ...base, talla: 'L' } // { color: 'rojo', talla: 'L' }
```

Las propiedades de la derecha **sobrescriben** a las de la izquierda. Esta es LA forma de "modificar" objetos sin mutarlos, y la usarás constantemente en React:

```js
const tareaHecha = { ...tarea, hecha: true }
```

### Como argumentos

```js
const nums = [5, 1, 9]
Math.max(...nums) // 9
```

## Rest: agrupar

En parámetros o destructuring, `...` **recoge el resto** en un array u objeto.

### Parámetros

```js
function sumar(...nums) {
  return nums.reduce((a, n) => a + n, 0)
}
sumar(1, 2, 3) // 6
```

### Destructuring

```js
const [primero, ...resto] = [1, 2, 3, 4] // primero = 1, resto = [2, 3, 4]

const { password, ...publico } = usuario // publico = todo menos password
```

## Copia superficial

Spread copia **un nivel**. Los objetos anidados se siguen compartiendo:

```js
const a = { datos: { x: 1 } }
const b = { ...a }
b.datos.x = 2
a.datos.x // 2 😬
```

Para copiar a fondo: `structuredClone(a)`.

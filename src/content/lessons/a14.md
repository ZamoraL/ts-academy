Un **array** es una lista ordenada de valores.

## Crear y leer

```js
const frutas = ['manzana', 'pera', 'uva']
frutas[0]       // 'manzana'  (los índices empiezan en 0)
frutas[2]       // 'uva'
frutas[5]       // undefined
frutas.length   // 3
frutas.at(-1)   // 'uva' (último elemento)
```

## Modificar

```js
frutas[1] = 'kiwi'     // reemplaza
frutas.push('mango')   // añade al final
frutas.pop()           // quita el último y lo devuelve
frutas.unshift('fresa') // añade al inicio
frutas.shift()          // quita el primero
```

`const` no impide modificar el contenido del array; solo impide reasignar la variable (`frutas = []` sí falla).

## Buscar

```js
const nums = [10, 20, 30, 20]
nums.includes(20)    // true
nums.indexOf(20)     // 1  (primera aparición; -1 si no está)
```

## Copiar partes y unir

```js
nums.slice(1, 3)       // [20, 30] (no modifica el original)
[1, 2].concat([3, 4])  // [1, 2, 3, 4]
['a', 'b'].join('-')   // 'a-b'
```

## Métodos que mutan vs los que no

| Mutan el array | Devuelven uno nuevo |
|---|---|
| `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse` | `slice`, `concat`, `map`, `filter`, `toSorted`, `toReversed` |

En React casi siempre querrás **no mutar**: crear arrays nuevos. Te conviene acostumbrarte ya.

## Ordenar

```js
[3, 1, 2].toSorted()                  // [1, 2, 3]
[10, 9, 100].toSorted()               // [10, 100, 9]  😱 ordena como texto
[10, 9, 100].toSorted((a, b) => a - b) // [9, 10, 100]
```

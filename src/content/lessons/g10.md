Un **input controlado** es aquel cuyo valor viene del estado de React. React es la "única fuente de verdad".

```jsx
function Buscador() {
  const [texto, setTexto] = useState('')
  return (
    <>
      <input value={texto} onChange={(e) => setTexto(e.target.value)} />
      <p>Buscando: {texto}</p>
    </>
  )
}
```

1. `value={texto}`: el input muestra lo que hay en el estado.
2. `onChange`: cada tecla actualiza el estado.
3. Nuevo render con el valor nuevo.

Si pones `value` sin `onChange`, el input queda bloqueado (React avisa en consola).

## Labels

Asocia cada input con su etiqueta. Mejora la accesibilidad y permite hacer clic en el texto:

```jsx
<label>
  Nombre
  <input value={nombre} onChange={(e) => setNombre(e.target.value)} />
</label>

// o con htmlFor + id
<label htmlFor="email">Email</label>
<input id="email" ... />
```

Los tests de los ejercicios buscan inputs **por su label**, igual que lo haría un usuario o un lector de pantalla.

## Otros tipos de input

```jsx
// checkbox: checked en vez de value
<input type="checkbox" checked={acepto} onChange={(e) => setAcepto(e.target.checked)} />

// select
<select value={pais} onChange={(e) => setPais(e.target.value)}>
  <option value="mx">México</option>
  <option value="es">España</option>
</select>

// textarea: también con value
<textarea value={mensaje} onChange={(e) => setMensaje(e.target.value)} />

// número: e.target.value siempre es string
<input type="number" value={edad} onChange={(e) => setEdad(Number(e.target.value))} />
```

## Enviar el formulario

```jsx
function Formulario({ onAgregar }) {
  const [titulo, setTitulo] = useState('')

  function manejarSubmit(e) {
    e.preventDefault()          // evita que el navegador recargue la página
    if (!titulo.trim()) return
    onAgregar(titulo.trim())
    setTitulo('')                // limpia el input
  }

  return (
    <form onSubmit={manejarSubmit}>
      <label>
        Nueva tarea
        <input value={titulo} onChange={(e) => setTitulo(e.target.value)} />
      </label>
      <button type="submit">Agregar</button>
    </form>
  )
}
```

Usar `<form onSubmit>` (en vez de `onClick` en el botón) hace que también funcione al pulsar Enter.

## Validación

Con inputs controlados, validar es calcular a partir del estado:

```jsx
const emailValido = email.includes('@')

<button disabled={!emailValido}>Enviar</button>
{!emailValido && email !== '' && <p>Email inválido</p>}
```

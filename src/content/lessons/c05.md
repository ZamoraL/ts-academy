## Los tres primitivos

```ts
const nombre: string = 'Ada'
const edad: number = 36
const activa: boolean = true
```

Siempre en **minúscula**. `String`, `Number` y `Boolean` (con mayúscula) existen, pero se refieren a objetos envoltorio que casi nunca quieres usar.

## Arrays

Dos sintaxis equivalentes:

```ts
const nums: number[] = [1, 2, 3]
const nombres: Array<string> = ['Ana', 'Luis']
```

La primera es la más común. La segunda (`Array<T>`) es un **genérico**: lo entenderás en el bloque E.

TS impide mezclar tipos:

```ts
nums.push('cuatro')
// Error: Argument of type 'string' is not assignable to parameter of type 'number'.
```

Y conoce el tipo de lo que devuelven los métodos:

```ts
const dobles = nums.map((n) => n * 2)    // number[]
const textos = nums.map((n) => `#${n}`)  // string[]
const primero = nums.find((n) => n > 1)  // number | undefined
```

Fíjate en el último: `find` puede no encontrar nada, y TS lo refleja en el tipo. Volveremos a esto.

## Arrays de varios tipos

Si de verdad necesitas mezclar:

```ts
const mezcla: (string | number)[] = [1, 'dos', 3]
```

Los paréntesis importan: `string | number[]` sería "un string, o un array de números".

## Inferencia en arrays

```ts
const a = [1, 2, 3]       // number[]
const b = [1, 'a']        // (string | number)[]
const c = []              // any[] → evítalo, anótalo
const d: string[] = []    // ✓
```

## Arrays de arrays

```ts
const matriz: number[][] = [
  [1, 2],
  [3, 4],
]
```

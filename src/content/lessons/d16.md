TS añade **modificadores de visibilidad** a los miembros de una clase.

## public

El defecto. Accesible desde cualquier sitio. Escribirlo es opcional.

```ts
class Saludador {
  public saludar() { return 'hola' }
}
```

## private

Solo accesible **dentro de la clase**:

```ts
class Cuenta {
  private saldo = 0

  depositar(m: number) {
    this.saldo += m // ✓
  }
}

const c = new Cuenta()
c.saldo
// Error: Property 'saldo' is private and only accessible within class 'Cuenta'.
```

## protected

Accesible en la clase **y en sus subclases**, pero no desde fuera:

```ts
class Empleado {
  protected salario: number
  constructor(salario: number) {
    this.salario = salario
  }
}

class Gerente extends Empleado {
  bono() {
    return this.salario * 0.2 // ✓ subclase
  }
}

new Gerente(1000).salario
// Error: Property 'salario' is protected and only accessible within class 'Empleado' and its subclasses.
```

## private de TS vs #private de JS

| | `private x` | `#x` |
|---|---|---|
| Quién lo impone | El compilador | JavaScript en runtime |
| ¿Se puede acceder con `obj['x']`? | Sí (TS lo permite como escape) | No |
| Visible en `JSON.stringify`, `Object.keys` | Sí | No |

`#x` es privacidad **real**. `private` es privacidad "de compilación", más flexible. Ambos son válidos; elige uno por proyecto.

## Parameter properties

Un atajo muy usado: un modificador en un parámetro del constructor **declara e inicializa** el campo en un paso.

```ts
// largo
class Usuario {
  readonly id: number
  private email: string
  constructor(id: number, email: string) {
    this.id = id
    this.email = email
  }
}

// corto, equivalente
class Usuario {
  constructor(
    readonly id: number,
    private email: string,
  ) {}
}
```

Funciona con `public`, `private`, `protected` y `readonly`.

> Nota: la opción `erasableSyntaxOnly` (TS 5.8+) prohíbe esta sintaxis, porque genera código. Algunos proyectos modernos la activan; esta app, por ejemplo. Si la ves, usa la forma larga.

## ¿Qué hacer privado?

Todo lo que no sea parte de lo que la clase **promete** a quien la usa. Lo privado se puede cambiar sin romper a nadie.

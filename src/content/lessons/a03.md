Cada valor en JavaScript tiene un **tipo**. Los tipos más básicos se llaman *primitivos*.

## Los primitivos que usarás siempre

| Tipo | Ejemplos | Para qué |
|---|---|---|
| `string` | `'hola'`, `"mundo"` | Texto |
| `number` | `42`, `3.14`, `-7` | Números (enteros y decimales son el mismo tipo) |
| `boolean` | `true`, `false` | Sí / no |
| `undefined` | `undefined` | "Todavía no tiene valor" |
| `null` | `null` | "Vacío a propósito" |

Hay dos más (`bigint` y `symbol`) que verás poco.

## typeof

El operador `typeof` te dice el tipo de un valor como texto:

```js
typeof 'hola'     // 'string'
typeof 42         // 'number'
typeof true       // 'boolean'
typeof undefined  // 'undefined'
typeof null       // 'object'  ← error histórico del lenguaje
```

Ese último caso es famoso: `typeof null` devuelve `'object'` por un bug de 1995 que ya no se puede arreglar.

## undefined vs null

```js
let respuesta
console.log(respuesta) // undefined: declarada pero sin valor

let usuario = null     // lo dejamos vacío a propósito
```

## Conversiones

```js
Number('42')    // 42
Number('hola')  // NaN  (Not a Number, ¡que es de tipo number!)
String(42)      // '42'
Boolean(0)      // false
```

`NaN` aparece cuando una operación numérica no tiene sentido. Para comprobarlo usa `Number.isNaN(x)`.

> **Por qué importa:** TypeScript es, en esencia, un sistema para que estos tipos queden escritos y comprobados antes de ejecutar el código.

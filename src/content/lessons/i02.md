## Crear el proyecto en tu computadora

Cuando quieras pasarlo a un proyecto real:

```bash
npm create vite@latest gastos -- --template react-ts
cd gastos
npm install
npm install zod
npm run dev
```

## Estructura de carpetas

No hay una única correcta, pero esta escala bien:

```
src/
  domain/
    tipos.ts         ← Gasto, Categoria, Filtros… (unidad 1)
    gastos.ts        ← funciones puras: totales, filtros, formato (esta unidad)
    reducer.ts       ← reducer y acciones (unidad 4)
  api/
    gastos.ts        ← fetch + validación con Zod (unidad 5)
  hooks/
    useGastos.ts
  components/
    ListaGastos.tsx  ← (unidad 3)
    FormularioGasto.tsx  (unidad 6)
    Resumen.tsx
  App.tsx
  main.tsx
```

La idea clave: **separar la lógica del dominio de React**. Las funciones de `domain/` son TypeScript puro: no importan React, se prueban con tests rápidos y se pueden reutilizar (por ejemplo, en un servidor).

## Funciones puras del dominio

```ts
export function totalPorCategoria(gastos: readonly Gasto[]): ResumenPorCategoria {
  const resumen = Object.fromEntries(CATEGORIAS.map((c) => [c, 0])) as ResumenPorCategoria
  for (const g of gastos) resumen[g.categoria] += g.monto
  return resumen
}
```

- `readonly Gasto[]`: documenta que no se modifica, y acepta arrays normales y readonly.
- Empezar con todas las categorías en 0 garantiza que el `Record` esté completo.

### Formatear dinero

No reinventes: `Intl.NumberFormat` conoce los formatos de cada país.

```ts
const formato = new Intl.NumberFormat('es-MX', { style: 'currency', currency: 'MXN' })
formato.format(1234.5) // '$1,234.50'
```

Crea el formateador **una vez** fuera de la función: construirlo es relativamente caro.

### Redondeo de dinero

Recuerda el `0.1 + 0.2` del bloque A. Para sumar montos, redondea a centavos:

```ts
const redondear = (n: number) => Math.round(n * 100) / 100
```

(En sistemas financieros reales se guardan centavos como enteros.)

Las **funciones flecha** son una forma más corta de escribir funciones. Son las que más verás en código moderno y en React.

## Sintaxis

```js
// declaración clásica
function doble(n) {
  return n * 2
}

// función flecha
const doble = (n) => {
  return n * 2
}

// si el cuerpo es una sola expresión, el return es implícito
const doble = (n) => n * 2
```

## Variantes

```js
const saludar = () => 'hola'           // sin parámetros
const sumar = (a, b) => a + b          // varios parámetros
const cuadrado = n => n * n            // un parámetro: paréntesis opcionales
```

Para devolver un **objeto** con return implícito, envuélvelo en paréntesis (si no, `{` se interpreta como el cuerpo):

```js
const crearPunto = (x, y) => ({ x, y })
```

## Funciones como valores

En JavaScript las funciones son valores: puedes guardarlas en variables y **pasarlas como argumento** a otras funciones.

```js
const aplicar = (fn, valor) => fn(valor)
aplicar(doble, 5) // 10
aplicar((n) => n + 1, 5) // 6
```

Esto es la base de `map`, `filter` y muchas APIs que verás pronto.

## return termina la función

```js
const signo = (n) => {
  if (n > 0) return 'positivo'
  if (n < 0) return 'negativo'
  return 'cero'
}
```

## Diferencias con `function`

Las flechas no tienen su propio `this` (lo verás con clases) y no se pueden usar antes de declararse. Para el día a día, son intercambiables.

Las clases de JS que viste en el bloque B, ahora con tipos.

## Campos

En TS, los campos se **declaran** en el cuerpo de la clase con su tipo:

```ts
class Punto {
  x: number
  y: number

  constructor(x: number, y: number) {
    this.x = x
    this.y = y
  }
}
```

Con valor inicial, el tipo se infiere:

```ts
class Contador {
  valor = 0 // number
}
```

## strictPropertyInitialization

Con `strict`, cada campo debe inicializarse en su declaración **o** en el constructor:

```ts
class Mal {
  nombre: string
  // Error: Property 'nombre' has no initializer and is not definitely assigned in the constructor.
}
```

Si de verdad se inicializa en otro sitio (por ejemplo, un método `init()` que llama una librería), puedes usar `!`:

```ts
class Componente {
  elemento!: HTMLElement // "confía en mí"
}
```

…con los mismos riesgos que cualquier assertion.

## Constructores

Como funciones: con tipos, opcionales y valores por defecto. **No** llevan tipo de retorno.

```ts
class Punto {
  x: number
  y: number
  constructor(x = 0, y = 0) {
    this.x = x
    this.y = y
  }
}
```

Pueden tener sobrecargas igual que las funciones.

## Métodos

```ts
class Punto {
  // ...
  sumar(otro: Punto): Punto {
    return new Punto(this.x + otro.x, this.y + otro.y)
  }
}
```

Dentro de un método, usa siempre `this.` para acceder a los campos.

## Getters y setters

```ts
class Temperatura {
  private celsius = 0

  get fahrenheit(): number {
    return this.celsius * 9 / 5 + 32
  }

  set fahrenheit(f: number) {
    this.celsius = (f - 32) * 5 / 9
  }
}

const t = new Temperatura()
t.fahrenheit = 212
t.fahrenheit // 212
```

Si hay `get` pero no `set`, la propiedad es automáticamente `readonly`.

## readonly en campos

```ts
class Usuario {
  readonly id: number
  constructor(id: number) {
    this.id = id // ✓ en el constructor se puede
  }
  cambiar() {
    this.id = 2 // Error: Cannot assign to 'id' because it is a read-only property.
  }
}
```

## Una clase también es un tipo

```ts
function imprimir(p: Punto) { ... }
```

Y como TS es estructural, cualquier objeto con la misma forma es aceptado:

```ts
imprimir({ x: 1, y: 2, sumar: (o) => o }) // ✓ aunque no venga de new Punto
```

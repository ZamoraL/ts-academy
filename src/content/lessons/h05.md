## Inline: TS ya lo sabe

Cuando escribes el handler directamente en el JSX, TS infiere el tipo del evento por contexto:

```tsx
<input onChange={(e) => setTexto(e.target.value)} />
//               ^ e: ChangeEvent<HTMLInputElement>
```

Pasa el ratón sobre `e` en el editor para verlo.

## En una función aparte: anótalo

```tsx
import type { ChangeEvent, FormEvent, MouseEvent, KeyboardEvent } from 'react'

function manejarCambio(e: ChangeEvent<HTMLInputElement>) {
  setTexto(e.target.value)
}

function manejarSubmit(e: FormEvent<HTMLFormElement>) {
  e.preventDefault()
}

function manejarClic(e: MouseEvent<HTMLButtonElement>) {
  console.log(e.clientX, e.currentTarget.disabled)
}

function manejarTecla(e: KeyboardEvent<HTMLInputElement>) {
  if (e.key === 'Escape') cerrar()
}
```

El parámetro genérico es el **elemento** al que está conectado el handler.

## Tabla rápida

| Prop | Tipo del evento |
|---|---|
| `onChange` en input/textarea/select | `ChangeEvent<HTMLInputElement>` / `HTMLTextAreaElement` / `HTMLSelectElement` |
| `onSubmit` | `FormEvent<HTMLFormElement>` |
| `onClick` | `MouseEvent<HTMLButtonElement>` (o el elemento que sea) |
| `onKeyDown` | `KeyboardEvent<HTMLInputElement>` |
| `onFocus` / `onBlur` | `FocusEvent<HTMLInputElement>` |

**Truco:** si no recuerdas el tipo, escribe el handler inline, pasa el ratón sobre `e` y copia el tipo.

## target vs currentTarget

- `e.currentTarget`: el elemento **donde está el handler**. Siempre tiene el tipo del genérico.
- `e.target`: el elemento que **originó** el evento (puede ser un hijo). En `onChange` de un input es el mismo input.

## Tipar el handler como prop

Si un componente recibe un handler:

```tsx
interface CampoProps {
  valor: string
  onChange: (valor: string) => void   // ✅ el valor, no el evento
}
```

Pasar el valor ya extraído (en vez del evento) hace al componente más fácil de usar y de probar. Si de verdad necesitas el evento:

```tsx
import type { ChangeEventHandler } from 'react'

interface Props {
  onChange: ChangeEventHandler<HTMLInputElement>
}
```

## Inputs numéricos

`e.target.value` es **siempre** `string`, también en `type="number"`. Convierte:

```tsx
onChange={(e) => setEdad(e.target.valueAsNumber)} // NaN si está vacío
onChange={(e) => setEdad(Number(e.target.value))}
```

## Formularios con FormData

Para formularios no controlados:

```tsx
function manejarSubmit(e: FormEvent<HTMLFormElement>) {
  e.preventDefault()
  const datos = new FormData(e.currentTarget)
  const email = datos.get('email') // FormDataEntryValue | null
  if (typeof email !== 'string') return
}
```

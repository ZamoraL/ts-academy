**JSON** (JavaScript Object Notation) es el formato de texto estándar para intercambiar datos: APIs, archivos de configuración, `localStorage`...

## Se parece a JavaScript, pero es más estricto

```json
{
  "nombre": "Ada",
  "edad": 36,
  "lenguajes": ["Fortran", "Analytical Engine"],
  "activa": true,
  "jefe": null
}
```

- Las claves van **siempre entre comillas dobles**.
- Strings con comillas dobles.
- Sin comas finales, sin comentarios.
- Solo: strings, números, booleans, `null`, arrays y objetos. **No** hay `undefined`, funciones ni fechas.

## De objeto a texto: JSON.stringify

```js
const datos = { nombre: 'Ada', edad: 36 }
JSON.stringify(datos)          // '{"nombre":"Ada","edad":36}'
JSON.stringify(datos, null, 2) // con sangría de 2 espacios
```

Lo que no existe en JSON se pierde o se transforma:

```js
JSON.stringify({ a: undefined, f() {}, fecha: new Date(0) })
// '{"fecha":"1970-01-01T00:00:00.000Z"}'
```

## De texto a objeto: JSON.parse

```js
const texto = '{"nombre":"Ada","edad":36}'
const obj = JSON.parse(texto)
obj.edad // 36
```

Si el texto no es JSON válido, **lanza un `SyntaxError`**. Envuélvelo en `try/catch` cuando venga de fuera.

## Copia profunda (truco antiguo)

```js
const copia = JSON.parse(JSON.stringify(obj))
```

Funciona para datos simples, pero pierde fechas, `undefined`, Map, Set... Hoy es mejor `structuredClone(obj)`.

## Guardar en localStorage

```js
localStorage.setItem('prefs', JSON.stringify({ tema: 'oscuro' }))
const prefs = JSON.parse(localStorage.getItem('prefs') ?? '{}')
```

Así guarda esta misma app tu progreso.

> En TypeScript, `JSON.parse` devuelve `any`: TS no sabe qué forma tienen los datos. Verás cómo validarlos de forma segura en el bloque H.

En el proyecto F construiste una mini librería de validación. **[Zod](https://zod.dev)** es la versión profesional de esa misma idea, y es la más usada en el ecosistema TS.

## Definir un schema

```ts
import { z } from 'zod'

const Usuario = z.object({
  id: z.number(),
  nombre: z.string().min(1),
  email: z.string().email(),
  rol: z.enum(['admin', 'lector']),
  apodo: z.string().optional(),
})

type Usuario = z.infer<typeof Usuario>
// { id: number; nombre: string; email: string; rol: 'admin' | 'lector'; apodo?: string | undefined }
```

Igual que tu `Infer<typeof Schema>`: una sola definición, validación en runtime **y** tipo.

## parse y safeParse

```ts
const u = Usuario.parse(datosDesconocidos) // Usuario, o lanza ZodError

const r = Usuario.safeParse(datosDesconocidos)
if (r.success) {
  r.data      // Usuario
} else {
  r.error.issues // [{ path: ['email'], message: 'Invalid email', ... }]
}
```

`safeParse` devuelve una unión discriminada por `success`. Ya sabes manejar eso.

## Validar respuestas de API

Reemplaza el `as T` inseguro:

```ts
const Posts = z.array(z.object({ id: z.number(), title: z.string() }))

async function obtenerPosts() {
  const r = await fetch('/api/posts')
  return Posts.parse(await r.json()) // tipo inferido y comprobado
}
```

Si la API devuelve algo inesperado, el error aparece **aquí**, con un mensaje claro, no tres componentes más allá.

## Validar formularios

```ts
const Registro = z
  .object({
    email: z.string().email('Email inválido'),
    contraseña: z.string().min(8, 'Mínimo 8 caracteres'),
    repetir: z.string(),
  })
  .refine((d) => d.contraseña === d.repetir, { message: 'No coinciden', path: ['repetir'] })

const r = Registro.safeParse(valores)
if (!r.success) {
  const errores = r.error.flatten().fieldErrors
  // { email?: string[]; contraseña?: string[]; repetir?: string[] }
}
```

Librerías de formularios como React Hook Form se integran directamente con Zod.

## Más herramientas

```ts
z.string().trim().toLowerCase()           // transformaciones
z.coerce.number()                         // convierte '42' → 42 (útil con inputs)
z.union([z.string(), z.number()])
z.discriminatedUnion('tipo', [A, B])
z.record(z.string(), z.number())
Usuario.partial()                          // todo opcional, como Partial
Usuario.pick({ nombre: true })             // como Pick
Usuario.extend({ edad: z.number() })
```

Fíjate cuánto se parece a los utility types: Zod es TypeScript en runtime.

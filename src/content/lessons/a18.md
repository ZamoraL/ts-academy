Un **objeto** agrupa valores con nombre (propiedades).

## Crear y leer

```js
const persona = {
  nombre: 'Ada',
  edad: 36,
  programadora: true,
}

persona.nombre      // 'Ada'
persona['edad']     // 36  (útil cuando la clave está en una variable)
persona.altura      // undefined
```

```js
const clave = 'nombre'
persona[clave] // 'Ada'
```

## Modificar

```js
persona.edad = 37       // cambiar
persona.ciudad = 'Londres' // añadir
delete persona.programadora // eliminar
```

## Abreviatura de propiedades

Si la variable se llama igual que la propiedad:

```js
const nombre = 'Ada'
const edad = 36
const p = { nombre, edad } // { nombre: 'Ada', edad: 36 }
```

## Métodos

Una propiedad que es una función:

```js
const contador = {
  valor: 0,
  incrementar() {
    this.valor++
  },
}
contador.incrementar()
contador.valor // 1
```

`this` dentro de un método se refiere al objeto. Lo verás a fondo con clases.

## Recorrer un objeto

```js
Object.keys(persona)    // ['nombre', 'edad', ...]
Object.values(persona)  // ['Ada', 36, ...]
Object.entries(persona) // [['nombre', 'Ada'], ['edad', 36], ...]

for (const [clave, valor] of Object.entries(persona)) {
  console.log(clave, valor)
}
```

## ¿Existe la propiedad?

```js
'nombre' in persona // true
```

## Objetos anidados

```js
const usuario = {
  nombre: 'Ana',
  direccion: { ciudad: 'Lima', cp: '15001' },
}
usuario.direccion.ciudad // 'Lima'
```

## Referencias

Los objetos se copian **por referencia**:

```js
const a = { x: 1 }
const b = a
b.x = 2
a.x // 2  ¡es el mismo objeto!
```

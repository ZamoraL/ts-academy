El formulario para registrar un gasto: inputs controlados, validación con Zod y errores por campo.

## Los valores del formulario son strings

Un `<input type="number">` da `'12.5'`, no `12.5`. Por eso el estado del formulario es distinto del tipo `NuevoGasto`:

```ts
interface ValoresFormulario {
  descripcion: string
  monto: string
  categoria: Categoria
  fecha: string
}
```

Zod convierte y valida a la vez:

```ts
const FormularioSchema = z.object({
  descripcion: z.string().trim().min(3, 'Mínimo 3 caracteres'),
  monto: z.coerce.number().positive('Debe ser mayor que 0'),
  categoria: z.enum(CATEGORIAS),
  fecha: z.string().regex(/^\d{4}-\d{2}-\d{2}$/, 'Fecha inválida'),
})
```

- `trim()` limpia espacios **antes** de validar la longitud.
- `z.coerce.number()` convierte `'12.5'` → `12.5` (y `'abc'` → `NaN`, que no pasa `positive`).
- Cada regla con su mensaje en español.

El resultado de `safeParse` ya tiene la forma de `NuevoGasto`.

## Errores por campo

```ts
const r = FormularioSchema.safeParse(valores)
if (!r.success) {
  const errores = r.error.flatten().fieldErrors
  // { descripcion?: string[]; monto?: string[]; ... }
}
```

Guárdalos en el estado y muéstralos junto a cada campo:

```tsx
<label>
  Monto
  <input
    type="number"
    value={valores.monto}
    aria-invalid={errores.monto ? true : undefined}
    aria-describedby={errores.monto ? 'error-monto' : undefined}
    onChange={...}
  />
</label>
{errores.monto && <p id="error-monto">{errores.monto[0]}</p>}
```

`aria-invalid` y `aria-describedby` hacen que un lector de pantalla anuncie el error al llegar al campo.

## Actualizar un campo de forma genérica

```ts
function cambiar<K extends keyof ValoresFormulario>(campo: K, valor: ValoresFormulario[K]) {
  setValores((v) => ({ ...v, [campo]: valor }))
}
```

Un solo handler tipado para todos los campos (bloque E en acción).

## Cuándo validar

- Al enviar: siempre.
- Mientras escribe: opcional; muchas apps validan un campo al salir de él (`onBlur`) para no mostrar errores mientras el usuario todavía está escribiendo.

En proyectos grandes, **React Hook Form** + Zod resuelve todo esto con menos código. Con lo que sabes ahora, entenderás exactamente qué hace por dentro.

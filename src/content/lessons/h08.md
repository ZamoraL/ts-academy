Un **custom hook** es una función cuyo nombre empieza por `use` y que llama a otros hooks. Sirve para **reutilizar lógica con estado** entre componentes.

## Extraer lógica

```tsx
function useContador(inicial = 0) {
  const [valor, setValor] = useState(inicial)
  const incrementar = () => setValor((v) => v + 1)
  const reiniciar = () => setValor(inicial)
  return { valor, incrementar, reiniciar }
}

function A() {
  const { valor, incrementar } = useContador()
  ...
}
```

Cada componente que llama a `useContador` tiene **su propio** estado: se comparte la lógica, no los datos.

## Tipar el retorno

TS lo infiere, pero ojo con los arrays:

```tsx
function useToggle(inicial = false) {
  const [activo, setActivo] = useState(inicial)
  const alternar = () => setActivo((a) => !a)
  return [activo, alternar]
}
// retorno inferido: (boolean | (() => void))[]  😕
```

TS infiere un array de la unión, no una tupla. Soluciones:

```tsx
return [activo, alternar] as const                       // readonly [boolean, () => void]
// o anota el retorno
function useToggle(inicial = false): [boolean, () => void] { ... }
```

Devuelve un **objeto** si son más de dos valores (se pueden desestructurar por nombre); una **tupla** si son dos y quieres que se puedan renombrar (como `useState`).

## Hooks genéricos

```tsx
function useLocalStorage<T>(clave: string, inicial: T) {
  const [valor, setValor] = useState<T>(() => {
    const guardado = localStorage.getItem(clave)
    return guardado !== null ? (JSON.parse(guardado) as T) : inicial
  })

  useEffect(() => {
    localStorage.setItem(clave, JSON.stringify(valor))
  }, [clave, valor])

  return [valor, setValor] as const
}

const [tema, setTema] = useLocalStorage<'claro' | 'oscuro'>('tema', 'claro')
const [notas, setNotas] = useLocalStorage('notas', [] as string[])
```

(El `as T` confía en que lo guardado tiene la forma correcta. En el bloque H11 verás cómo validarlo de verdad.)

## Ejemplos útiles

- `useDebounce(valor, ms)`: devuelve el valor solo cuando deja de cambiar durante `ms`.
- `useFetch<T>(url)`: estado de carga/error/datos.
- `useMediaQuery('(max-width: 600px)')`: boolean.
- `useOnClickOutside(ref, fn)`: cerrar menús.

## Reglas

Las mismas que cualquier hook: solo en el nivel superior de componentes u otros hooks. El prefijo `use` no es decorativo: le dice a React (y al linter) que aplique esas reglas.

Los **genéricos** permiten escribir código que funciona con **muchos tipos** sin perder la información de cuál es.

## El problema

Una función que devuelve lo que recibe:

```ts
function identidad(x: number): number { return x }   // solo números
function identidad(x: any): any { return x }         // pierde el tipo
```

Con `any`, si pasas un número, TS ya no sabe que lo que vuelve es un número.

## Una variable de tipo

```ts
function identidad<T>(x: T): T {
  return x
}
```

`<T>` declara un **parámetro de tipo**: un hueco que se rellena en cada llamada. Se lee "para cualquier tipo T, recibe un T y devuelve un T".

```ts
const a = identidad('hola') // T = string → a: string
const b = identidad(42)     // T = number → b: number
```

TS **infiere** `T` a partir del argumento. También puedes indicarlo a mano:

```ts
identidad<string>('hola')
```

Normalmente no hace falta.

## Ya los usas

```ts
const nums: Array<number> = [1, 2]       // number[]
const p: Promise<string> = fetchTexto()
const m = new Map<string, number>()
const [v, setV] = useState<string>('')   // React
```

`Array`, `Promise`, `Map`, `Set` son tipos genéricos.

## Con arrays

```ts
function primero<T>(arr: T[]): T | undefined {
  return arr[0]
}

primero([1, 2, 3])     // number | undefined
primero(['a', 'b'])    // string | undefined
```

## Varios parámetros de tipo

```ts
function par<A, B>(a: A, b: B): [A, B] {
  return [a, b]
}

par('edad', 36) // [string, number]
```

```ts
function mapear<T, U>(arr: T[], fn: (x: T) => U): U[] {
  return arr.map(fn)
}

mapear([1, 2], (n) => n.toString()) // string[]
```

TS infiere `T = number` del array, y `U = string` de lo que devuelve la función.

## Nombres

Por convención: `T` (type), `U`, `K` (key), `V` (value), `E` (element). Cuando hay varios y no es obvio, usa nombres descriptivos: `TItem`, `TResultado`.

## Regla del Handbook

Si un parámetro de tipo **solo aparece una vez**, probablemente sobra:

```ts
function saludar<T extends string>(nombre: T) { console.log(nombre) } // ❌
function saludar(nombre: string) { console.log(nombre) }              // ✅
```

Los genéricos sirven para **relacionar** tipos: entrada con salida, un parámetro con otro.

La estructura de datos más común en aplicaciones reales: **una lista de objetos**. Una respuesta de API, una lista de tareas, un carrito de compras...

```js
const productos = [
  { id: 1, nombre: 'Teclado', precio: 50, stock: 3 },
  { id: 2, nombre: 'Ratón', precio: 20, stock: 0 },
  { id: 3, nombre: 'Monitor', precio: 200, stock: 5 },
]
```

## Todo lo que ya sabes, combinado

```js
// nombres
productos.map((p) => p.nombre)              // ['Teclado', 'Ratón', 'Monitor']

// disponibles
productos.filter((p) => p.stock > 0)

// buscar por id
productos.find((p) => p.id === 3)

// valor total del inventario
productos.reduce((total, p) => total + p.precio * p.stock, 0) // 1150

// ¿hay algo agotado?
productos.some((p) => p.stock === 0)        // true
```

## Ordenar por una propiedad

```js
productos.toSorted((a, b) => a.precio - b.precio)          // por precio ascendente
productos.toSorted((a, b) => a.nombre.localeCompare(b.nombre)) // alfabético
```

## Transformar la forma

```js
productos.map((p) => ({ nombre: p.nombre, disponible: p.stock > 0 }))
```

Recuerda los paréntesis `({ ... })` para devolver un objeto desde una flecha.

## Agrupar

```js
const porDisponibilidad = Object.groupBy(productos, (p) => (p.stock > 0 ? 'disponibles' : 'agotados'))
// { disponibles: [...], agotados: [...] }
```

> En TypeScript describirás la forma de estos objetos con una `interface` o un `type`, y el editor te avisará si escribes `p.precoi` en vez de `p.precio`.

En el bloque B viste los módulos de JavaScript (`import`/`export`). TypeScript usa exactamente esa sintaxis, y añade la posibilidad de **exportar e importar tipos**.

## Qué es un módulo en TS

Cualquier archivo con un `import` o `export` de nivel superior es un módulo: sus declaraciones son locales. Un archivo **sin** ninguno es un *script*: sus declaraciones son globales y se ven desde todos los demás scripts.

```ts
// sin import/export: x es global 😬
const x = 1
```

Para forzar que un archivo sea módulo sin exportar nada, se usaba `export {}`. Hoy, con `moduleDetection: "force"` (que usa esta app), todo archivo es módulo.

## Exportar tipos

Los tipos se exportan igual que los valores:

```ts
// usuarios.ts
export interface Usuario {
  id: number
  nombre: string
}

export type Rol = 'admin' | 'lector'

export function crearUsuario(nombre: string): Usuario {
  return { id: Date.now(), nombre }
}
```

```ts
// app.ts
import { crearUsuario, type Usuario, type Rol } from './usuarios'

const u: Usuario = crearUsuario('Ada')
```

## Rutas de importación

Depende de la configuración (`moduleResolution`):

```ts
import { x } from './usuarios'      // bundler (Vite, Next): sin extensión
import { x } from './usuarios.js'   // Node ESM: con .js, aunque el archivo sea .ts
```

Sí, en Node con ESM importas `.js` desde un `.ts`: la ruta se refiere al archivo **que existirá** tras compilar.

## Reexportar

```ts
// index.ts: un punto de entrada para una carpeta
export { crearUsuario } from './usuarios'
export type { Usuario } from './usuarios'
export * from './pedidos'
```

## Organización típica

```
src/
  types.ts           ← tipos compartidos del dominio
  lib/
    fecha.ts
    api.ts
  components/
```

Esta misma app sigue esa estructura: mira `src/types.ts`, donde están `Unit`, `Exercise`, `PlanConfig`...

## Los tipos no existen en runtime

Exportar una `interface` no genera código. Si un archivo **solo** importa tipos de otro, ese import desaparece al compilar. Esto tiene consecuencias que verás en la siguiente unidad.

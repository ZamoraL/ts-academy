Una **clase** es una plantilla para crear objetos con la misma forma y comportamiento.

## Sintaxis

```js
class Rectangulo {
  constructor(ancho, alto) {
    this.ancho = ancho
    this.alto = alto
  }

  area() {
    return this.ancho * this.alto
  }

  escalar(factor) {
    this.ancho *= factor
    this.alto *= factor
  }
}

const r = new Rectangulo(2, 3)
r.area()     // 6
r.escalar(2)
r.area()     // 24
```

- `constructor` se ejecuta al hacer `new`. Inicializa las propiedades.
- `this` es el objeto que se está creando / usando.
- Los métodos se comparten entre todas las instancias.

## Campos de clase

Puedes declarar propiedades directamente:

```js
class Contador {
  valor = 0
  incrementar() {
    this.valor++
  }
}
```

## Campos privados

Con `#`, la propiedad solo es accesible dentro de la clase:

```js
class Cuenta {
  #saldo = 0
  depositar(m) {
    this.#saldo += m
  }
  get saldo() {
    return this.#saldo
  }
}
const c = new Cuenta()
c.depositar(50)
c.saldo   // 50 (getter)
c.#saldo  // SyntaxError
```

## Getters y estáticos

```js
class Temperatura {
  constructor(celsius) {
    this.celsius = celsius
  }
  get fahrenheit() {
    return this.celsius * 9 / 5 + 32
  }
  static desdeFahrenheit(f) {
    return new Temperatura((f - 32) * 5 / 9)
  }
}
new Temperatura(100).fahrenheit        // 212 (se usa sin paréntesis)
Temperatura.desdeFahrenheit(32).celsius // 0 (static: se llama en la clase)
```

## instanceof

```js
r instanceof Rectangulo // true
```

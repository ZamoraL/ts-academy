Vas a construir un **cliente para una API de usuarios y posts**, con el formato de [JSONPlaceholder](https://jsonplaceholder.typicode.com).

## La API

```
GET {base}/users/{id}         → { id, name, email, ... }
GET {base}/posts?userId={id}  → [{ id, userId, title, body }, ...]
```

Si el recurso no existe, responde con status `404`.

## Qué implementar

Una función `crearCliente(base)` que devuelva un objeto con estos métodos (todos `async`):

1. `usuario(id)`: devuelve el usuario. Si la respuesta no es `ok`, lanza `Error('HTTP <status>')`.
2. `postsDe(userId)`: devuelve el array de posts de ese usuario.
3. `resumen(id)`: carga el usuario **y** sus posts **en paralelo** y devuelve:

```js
{ nombre: 'Leanne Graham', email: 'Sincere@april.biz', totalPosts: 10, titulos: ['...', ...] }
```

## Pistas

- Escribe primero una función auxiliar `getJSON(url)` dentro de `crearCliente`, que haga el `fetch`, compruebe `ok` y devuelva `r.json()`. Los tres métodos la usan.
- Construye las URLs con template literals: `` `${base}/users/${id}` ``.
- Para el paralelo: `Promise.all([...])` con destructuring.
- Tu objeto puede usar closures: `base` queda capturado.

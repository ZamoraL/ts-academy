Un pequeño sistema de **inventario** con clases tipadas: clases, visibilidad, readonly, errores personalizados, `Map` e interfaces.

## Qué construir

### `interface Producto`

`readonly sku: string`, `nombre: string`, `precio: number`.

### `class StockInsuficienteError extends Error`

- Constructor `(sku: string, pedido: number, disponible: number)`.
- `name = 'StockInsuficienteError'`, mensaje `'Stock insuficiente de <sku>: pedido <pedido>, disponible <disponible>'`.
- Guarda `sku`, `pedido` y `disponible` como propiedades `readonly`.

### `class Inventario`

Internamente guarda un `Map<string, { producto: Producto; cantidad: number }>` **privado**.

- `agregar(producto: Producto, cantidad: number): void`: si el SKU ya existe, suma la cantidad (y actualiza nombre/precio con el nuevo producto).
- `retirar(sku: string, cantidad: number): void`: resta. Si el SKU no existe, la cantidad disponible es 0. Si no alcanza, lanza `StockInsuficienteError`.
- `cantidadDe(sku: string): number`: 0 si no existe.
- `buscar(sku: string): Producto | undefined`.
- `get valorTotal(): number`: suma de `precio × cantidad`.
- `listar(): readonly Producto[]`: productos con cantidad > 0, ordenados por nombre.

## Requisitos de tipos

Los tests de tipos comprobarán que:

- no se puede acceder al Map interno desde fuera,
- no se puede reasignar `valorTotal` ni el `sku` de un producto,
- lo que devuelve `listar()` no se puede modificar con `push`.

## Pista

La forma de declarar el Map privado:

```ts
private stock = new Map<string, { producto: Producto; cantidad: number }>()
```

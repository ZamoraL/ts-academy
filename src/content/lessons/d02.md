## Truthiness narrowing

En un `if`, TS sabe que los valores falsy (`0`, `''`, `null`, `undefined`, `NaN`, `false`) no pasan. Así puedes descartar `null` y `undefined`:

```ts
function imprimirTodos(strs: string | string[] | null) {
  if (strs && typeof strs === 'object') {
    for (const s of strs) console.log(s) // strs: string[]
  } else if (typeof strs === 'string') {
    console.log(strs)
  }
}
```

### Cuidado: no envuelvas todo en un if

```ts
function imprimirTodos(strs: string | string[] | null) {
  // ❌ no hagas esto
  if (strs) {
    if (typeof strs === 'object') { ... }
    else if (typeof strs === 'string') { ... }
  }
}
```

Parece igual, pero ahora el **string vacío** `''` no entra al `if` y no se imprime. Truthiness descarta más que `null`.

### Negación

```ts
function multiplicarTodos(valores: number[] | undefined, factor: number) {
  if (!valores) return valores        // valores: undefined
  return valores.map((x) => x * factor) // valores: number[]
}
```

## Equality narrowing

`===`, `!==`, `==` y `!=` también estrechan:

```ts
function ejemplo(x: string | number, y: string | boolean) {
  if (x === y) {
    // el único tipo en común es string
    x.toUpperCase() // x: string
    y.toLowerCase() // y: string
  }
}
```

Comparar con `null` es la forma más precisa de descartarlo:

```ts
function imprimirTodos(strs: string | string[] | null) {
  if (strs !== null) {
    // strs: string | string[]   (el '' sí entra)
  }
}
```

### `== null`

`x != null` descarta **a la vez** `null` y `undefined`. Es el único uso de `==` aceptado por muchos equipos:

```ts
function f(x: number | null | undefined) {
  if (x != null) {
    x.toFixed() // x: number
  }
}
```

## Resumen

| Comprobación | Descarta |
|---|---|
| `if (x)` | todos los falsy (incluye `0` y `''`) |
| `if (x !== null)` | solo `null` |
| `if (x !== undefined)` | solo `undefined` |
| `if (x != null)` | `null` y `undefined` |

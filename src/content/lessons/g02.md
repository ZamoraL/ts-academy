## Un componente es una función

```jsx
function Saludo() {
  return <h1>Hola, mundo</h1>
}
```

Reglas:

1. El nombre empieza con **mayúscula** (`Saludo`, no `saludo`). Así React distingue tus componentes de las etiquetas HTML.
2. Devuelve **JSX** (lo que parece HTML).

## Usar un componente

Se usa como una etiqueta:

```jsx
function App() {
  return (
    <div>
      <Saludo />
      <Saludo />
    </div>
  )
}
```

Así construyes interfaces **componiendo** piezas pequeñas.

## Exportar

Cada componente suele vivir en su propio archivo:

```jsx
// Saludo.jsx
export default function Saludo() {
  return <h1>Hola</h1>
}

// App.jsx
import Saludo from './Saludo'
```

En los ejercicios, el componente que exportes con `export default` es el que aparece en la vista previa.

## Paréntesis en el return

Si el JSX ocupa varias líneas, envuélvelo en paréntesis. Sin ellos, el `return` en una línea sola devuelve `undefined`:

```jsx
return (
  <div>
    ...
  </div>
)
```

## Un solo elemento raíz

Un componente devuelve **un** elemento. Para devolver varios sin añadir un `<div>`, usa un **fragmento**:

```jsx
function Lista() {
  return (
    <>
      <li>Uno</li>
      <li>Dos</li>
    </>
  )
}
```

## No declares componentes dentro de otros

```jsx
// ❌
function App() {
  function Boton() { return <button>x</button> }
  return <Boton />
}
```

Se recrea en cada render y pierde su estado. Decláralos siempre en el nivel superior del archivo.

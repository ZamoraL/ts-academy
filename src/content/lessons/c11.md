Un **literal type** es un tipo que solo admite **un valor concreto**.

```ts
let x: 'hola' = 'hola'
x = 'adiós'
// Error: Type '"adiós"' is not assignable to type '"hola"'.
```

Solo no sirve de mucho. Combinado con uniones, es una de las herramientas más útiles de TS:

```ts
type Alineacion = 'izquierda' | 'derecha' | 'centro'

function alinear(texto: string, a: Alineacion) { }

alinear('Hola', 'izquierda') // ✓
alinear('Hola', 'centrado')
// Error: Argument of type '"centrado"' is not assignable to parameter of type 'Alineacion'.
```

El editor además **autocompleta** las opciones válidas.

## Números y booleans

```ts
type Dado = 1 | 2 | 3 | 4 | 5 | 6
type Comparacion = -1 | 0 | 1

function comparar(a: string, b: string): Comparacion {
  return a === b ? 0 : a > b ? 1 : -1
}
```

`boolean` en realidad es la unión `true | false`.

## Mezclar con otros tipos

```ts
interface Opciones { ancho: number }
function configurar(x: Opciones | 'auto') { }

configurar({ ancho: 100 }) // ✓
configurar('auto')         // ✓
configurar('automatico')   // Error
```

## let vs const

```ts
const a = 'GET'  // tipo: "GET"
let b = 'GET'    // tipo: string
```

Con `let`, TS amplía (*widening*) a `string` porque podrías reasignarla.

## El problema con objetos

```ts
declare function pedir(url: string, metodo: 'GET' | 'POST'): void

const req = { url: 'https://x.com', metodo: 'GET' }
pedir(req.url, req.metodo)
// Error: Argument of type 'string' is not assignable to parameter of type '"GET" | "POST"'.
```

`req.metodo` se infirió como `string` (las propiedades de un objeto se pueden reasignar). Soluciones:

```ts
// 1. as const: todo el objeto se vuelve literal y readonly
const req = { url: 'https://x.com', metodo: 'GET' } as const

// 2. anotar el objeto
const req: { url: string; metodo: 'GET' | 'POST' } = { url: '...', metodo: 'GET' }
```

## as const con arrays

```ts
const COLORES = ['rojo', 'verde', 'azul'] as const
// readonly ['rojo', 'verde', 'azul']
type Color = (typeof COLORES)[number] // 'rojo' | 'verde' | 'azul'
```

Así defines la lista una vez y obtienes el tipo gratis. Esa sintaxis la entenderás del todo en el bloque E.

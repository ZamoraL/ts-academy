Los operadores de comparación devuelven un `boolean`.

```js
5 > 3    // true
5 < 3    // false
5 >= 5   // true
5 <= 4   // false
```

## Igualdad: usa siempre `===`

JavaScript tiene dos igualdades:

```js
1 === 1     // true
1 === '1'   // false  (distinto tipo)

1 == '1'    // true   (convierte tipos antes de comparar)
0 == false  // true
'' == 0     // true   😱
```

`==` hace conversiones raras. **Regla: usa siempre `===` y `!==`.**

```js
'a' !== 'b' // true
```

## Comparar strings

Los strings se comparan alfabéticamente, carácter por carácter (por código Unicode):

```js
'a' < 'b'      // true
'Z' < 'a'      // true (las mayúsculas van antes)
'10' < '9'     // true (compara el carácter '1' con '9')
```

## NaN no es igual a nada

```js
NaN === NaN        // false
Number.isNaN(NaN)  // true
```

## Objetos y arrays

`===` con objetos compara si son **el mismo objeto**, no si tienen el mismo contenido:

```js
[1, 2] === [1, 2] // false
```

Lo verás con más detalle en la unidad de objetos.

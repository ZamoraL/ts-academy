## Crear strings

```js
const a = 'comillas simples'
const b = "comillas dobles"
const c = `backticks`
```

## Template literals

Con backticks puedes **insertar expresiones** con `${...}` y escribir varias líneas:

```js
const nombre = 'Ada'
const edad = 36
const msg = `${nombre} tiene ${edad} años. El año que viene tendrá ${edad + 1}.`
```

Es mucho más legible que concatenar con `+`.

## Propiedades y métodos útiles

```js
const s = 'Hola Mundo'
s.length            // 10
s[0]                // 'H'
s.toUpperCase()     // 'HOLA MUNDO'
s.toLowerCase()     // 'hola mundo'
s.includes('Mundo') // true
s.startsWith('Ho')  // true
s.indexOf('M')      // 5  (-1 si no está)
s.slice(0, 4)       // 'Hola'  (desde 0 hasta antes de 4)
s.slice(-5)         // 'Mundo' (negativos cuentan desde el final)
s.replace('Mundo', 'TS') // 'Hola TS'
'  hola  '.trim()   // 'hola'
'a,b,c'.split(',')  // ['a', 'b', 'c']
'ja'.repeat(3)      // 'jajaja'
'5'.padStart(3, '0') // '005'
```

## Los strings son inmutables

Los métodos **no modifican** el string: devuelven uno nuevo.

```js
const t = 'hola'
t.toUpperCase()
console.log(t) // 'hola'
const T = t.toUpperCase() // guárdalo en otra variable
```

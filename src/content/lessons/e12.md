Con `as` dentro de un mapped type puedes **renombrar** las claves, o **eliminarlas**.

## Sintaxis

```ts
type Mapeado<T> = {
  [K in keyof T as NuevaClave]: T[K]
}
```

## Renombrar con template literals

```ts
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K]
}

interface Persona {
  nombre: string
  edad: number
}

type G = Getters<Persona>
// { getNombre: () => string; getEdad: () => number }
```

- `Capitalize<S>` es un tipo intrínseco que pone la primera letra en mayúscula.
- `string & K` hace falta porque `keyof T` puede incluir `number` y `symbol`, y `Capitalize` solo acepta strings.

## Eliminar claves: as never

Si la nueva clave es `never`, la propiedad **desaparece**:

```ts
type SinKind<T> = {
  [K in keyof T as Exclude<K, 'kind'>]: T[K]
}

type Circulo = { kind: 'circulo'; radio: number }
type C = SinKind<Circulo> // { radio: number }
```

## Filtrar por el tipo del valor

```ts
type SoloMetodos<T> = {
  [K in keyof T as T[K] extends (...args: any[]) => any ? K : never]: T[K]
}

type SoloDatos<T> = {
  [K in keyof T as T[K] extends (...args: any[]) => any ? never : K]: T[K]
}

class Usuario {
  nombre = ''
  edad = 0
  saludar() { return 'hola' }
}

type M = SoloMetodos<Usuario> // { saludar: () => string }
type D = SoloDatos<Usuario>   // { nombre: string; edad: number }
```

`SoloDatos` es útil para obtener la forma "serializable" de una clase.

## Mapear sobre uniones de objetos

La clave del `in` puede ser cualquier unión, incluso de objetos:

```ts
type Evento = { tipo: 'click'; x: number } | { tipo: 'tecla'; codigo: string }

type Handlers = {
  [E in Evento as E['tipo']]: (e: E) => void
}
// { click: (e: { tipo: 'click'; x: number }) => void;
//   tecla: (e: { tipo: 'tecla'; codigo: string }) => void }
```

Un patrón muy usado para mapas de handlers tipados.

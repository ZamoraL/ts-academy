Última unidad: integrar las piezas en una app completa, pulirla y publicarla.

## Integrar

```
App                     ← useReducer(gastos), useState(filtros)
├─ FormularioGasto      → dispatch agregar
├─ Filtros              → setFiltros
├─ ListaGastos          ← gastos filtrados, → dispatch borrar
└─ Resumen              ← totales por categoría
```

El estado vive en `App`; los demás son presentacionales o tienen solo estado local (el formulario).

## useMemo para cálculos costosos

Los gastos filtrados y los totales se recalculan en cada render. Con pocos datos da igual; con miles, puedes memorizarlos:

```tsx
const filtrados = useMemo(() => filtrarGastos(gastos, filtros), [gastos, filtros])
const resumen = useMemo(() => totalPorCategoria(filtrados), [filtrados])
```

Regla: escribe primero sin `useMemo`; añádelo cuando midas un problema. (React Compiler, en versiones recientes, lo hace automáticamente.)

## Anunciar cambios: aria-live

Cuando algo cambia fuera del foco del usuario (se agregó un gasto, cambió el total), una región `aria-live` lo anuncia a lectores de pantalla:

```tsx
<p aria-live="polite">Total: {formatearMonto(total)}</p>
```

## Persistencia

Con el hook `useLocalStorage` de la unidad H8 (validando con Zod al leer), los gastos sobreviven a recargar la página.

## Construir y publicar

```bash
npm run build     # tsc -b && vite build → genera dist/
npm run preview   # sirve dist/ localmente para comprobar
```

`dist/` son archivos estáticos (HTML, JS, CSS): se publican en cualquier hosting estático.

- **Netlify** o **Vercel**: conecta tu repositorio de GitHub; cada `git push` publica automáticamente. Comando de build `npm run build`, carpeta `dist`.
- **GitHub Pages**: añade `base: '/nombre-repo/'` en `vite.config.ts` y publica `dist/` (por ejemplo con una GitHub Action).
- **Cloudflare Pages**: igual que Netlify.

Si usas rutas (React Router), configura el hosting para que todas las rutas sirvan `index.html`.

## ¿Y ahora qué?

Ya dominas JavaScript moderno, TypeScript de principio a fin y React con TypeScript. Caminos para seguir:

- **Next.js**: React con servidor, rutas y datos. La opción más usada para apps completas.
- **TanStack Query**: datos remotos con caché.
- **React Hook Form**: formularios grandes.
- **Node.js + TypeScript** (Hono, Express, Fastify): tu propio backend, reutilizando tus tipos y schemas de Zod.
- **Playwright**: tests end-to-end en navegador real.
- Lee el código de esta app (`ts-academy` en tu escritorio): ahora entiendes cada línea.

Y sobre todo: **construye proyectos propios**. Es como de verdad se aprende. 🎉

## Operadores lógicos

```js
true && false  // false   Y: ambos deben ser true
true || false  // true    O: basta con uno
!true          // false   NO: invierte
```

```js
const edad = 20
const tieneEntrada = true
const puedePasar = edad >= 18 && tieneEntrada // true
```

## Truthy y falsy

En una condición, cualquier valor se convierte a `boolean`. Solo estos valores son **falsy**:

- `false`
- `0` (y `-0`)
- `''` (string vacío)
- `null`
- `undefined`
- `NaN`

**Todo lo demás es truthy**, incluidos `'0'`, `'false'`, `[]` y `{}`.

```js
if ('hola') console.log('se ejecuta')
if (0) console.log('no se ejecuta')
```

## Cortocircuito

`&&` y `||` no devuelven necesariamente `true`/`false`: devuelven **uno de los operandos**.

```js
'Ana' || 'Invitado'   // 'Ana'      (el primero truthy)
'' || 'Invitado'      // 'Invitado'
'Ana' && 'Bienvenida' // 'Bienvenida' (si el primero es truthy, devuelve el segundo)
null && 'x'           // null
```

Uso clásico: valores por defecto.

```js
const nombre = nombreIngresado || 'Invitado'
```

Ojo: si `nombreIngresado` es `''` o `0`, también usa el defecto. En el bloque B verás `??`, que solo reacciona a `null` y `undefined`.

## Doble negación

`!!valor` convierte cualquier valor a su boolean: `!!'hola'` es `true`, `!!0` es `false`.

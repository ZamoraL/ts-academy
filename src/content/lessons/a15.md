## for clásico

Ya lo conoces; sirve cuando necesitas el índice:

```js
const nums = [5, 8, 2]
for (let i = 0; i < nums.length; i++) {
  console.log(i, nums[i])
}
```

## for...of

La forma más limpia de recorrer **valores**:

```js
for (const n of nums) {
  console.log(n) // 5, 8, 2
}
```

Funciona con arrays, strings y otras colecciones (`Map`, `Set`).

```js
for (const letra of 'hola') console.log(letra)
```

Si necesitas también el índice:

```js
for (const [i, n] of nums.entries()) {
  console.log(i, n)
}
```

## forEach

Un método del array que recibe una **función** y la llama con cada elemento:

```js
nums.forEach((n, i) => {
  console.log(i, n)
})
```

Limitaciones: no puedes usar `break` ni `return` para salir antes. Si necesitas salir, usa `for...of`.

## for...in (evítalo con arrays)

`for...in` recorre **claves** de un objeto. Con arrays da los índices como strings: confuso. Úsalo con objetos (o mejor `Object.keys`, que verás pronto).

## ¿Cuál uso?

- Recorrer valores: `for...of`.
- Necesito salir antes: `for...of` con `break`.
- Transformar o filtrar: `map` / `filter` (la próxima unidad), no bucles.

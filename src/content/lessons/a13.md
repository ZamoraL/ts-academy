El **alcance** (scope) define desde dónde se puede usar una variable.

## Alcance de bloque

`let` y `const` solo existen dentro del bloque `{ }` donde se declaran:

```js
if (true) {
  const mensaje = 'hola'
  console.log(mensaje) // 'hola'
}
console.log(mensaje) // ReferenceError: mensaje is not defined
```

Lo mismo pasa con bucles y funciones:

```js
for (let i = 0; i < 3; i++) {}
console.log(i) // ReferenceError
```

## Alcance de función

Los parámetros y variables de una función solo existen dentro de ella:

```js
function f() {
  const local = 1
}
f()
console.log(local) // ReferenceError
```

## Las funciones ven hacia afuera

Una función **puede leer** variables del alcance donde fue creada:

```js
const iva = 0.16
function conIva(precio) {
  return precio * (1 + iva) // iva viene de afuera
}
```

Pero lo de afuera **no ve** lo de adentro.

## Sombreado (shadowing)

Una variable interna con el mismo nombre "tapa" a la externa:

```js
const x = 'afuera'
function f() {
  const x = 'adentro'
  return x
}
f() // 'adentro'
x   // 'afuera'
```

## Por qué importa

- Variables con alcance pequeño son más fáciles de entender: menos sitios donde pueden cambiar.
- Evita modificar variables externas desde funciones; mejor recibe datos por parámetro y **devuelve** resultados. A eso se le llama **función pura**.

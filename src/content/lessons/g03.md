**JSX** parece HTML, pero es JavaScript: el compilador lo convierte en llamadas a funciones.

```jsx
const el = <h1 className="titulo">Hola</h1>
// se convierte en algo como:
const el = jsx('h1', { className: 'titulo', children: 'Hola' })
```

## Diferencias con HTML

| HTML | JSX | Por qué |
|---|---|---|
| `class="..."` | `className="..."` | `class` es palabra reservada en JS |
| `for="..."` | `htmlFor="..."` | `for` también |
| `onclick="..."` | `onClick={...}` | Atributos en camelCase |
| `<br>` | `<br />` | Toda etiqueta debe cerrarse |
| `style="color: red"` | `style={{ color: 'red' }}` | Un objeto JS |

## Llaves: JavaScript dentro de JSX

Con `{ }` insertas **cualquier expresión** de JavaScript:

```jsx
const nombre = 'Ada'
const items = 3

<p>Hola, {nombre}</p>
<p>Tienes {items * 2} mensajes</p>
<p>{nombre.toUpperCase()}</p>
<img src={usuario.avatar} alt={`Foto de ${nombre}`} />
```

Solo **expresiones** (cosas que producen un valor), no sentencias como `if` o `for`. Para eso verás alternativas en las próximas unidades.

## Doble llave en style

```jsx
<div style={{ backgroundColor: 'black', padding: 8 }}>
```

La llave exterior es "aquí va JS"; la interior es el objeto. Las propiedades CSS van en camelCase y los números se interpretan como píxeles.

## Qué se muestra

```jsx
<p>{42}</p>        // 42
<p>{'texto'}</p>   // texto
<p>{true}</p>      // nada
<p>{null}</p>      // nada
<p>{undefined}</p> // nada
<p>{[1, 2, 3]}</p> // 123
<p>{{ a: 1 }}</p>  // ❌ error: los objetos no se pueden renderizar
```

`true`, `false`, `null` y `undefined` no muestran nada: esto será útil para el renderizado condicional.

## Comentarios

```jsx
<div>

```

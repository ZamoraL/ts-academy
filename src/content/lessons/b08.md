Además de objetos y arrays, JavaScript tiene dos colecciones especializadas.

## Set: valores únicos

```js
const s = new Set([1, 2, 2, 3])
s.size        // 3
s.has(2)      // true
s.add(4)
s.delete(1)

for (const v of s) console.log(v)
```

El truco más usado: **quitar duplicados**.

```js
const unicos = [...new Set(['a', 'b', 'a'])] // ['a', 'b']
```

`has` en un Set es mucho más rápido que `includes` en un array grande.

## Map: diccionario con cualquier clave

```js
const edades = new Map()
edades.set('Ana', 30)
edades.set('Luis', 25)

edades.get('Ana')   // 30
edades.get('Eva')   // undefined
edades.has('Luis')  // true
edades.size         // 2
edades.delete('Ana')

for (const [nombre, edad] of edades) {
  console.log(nombre, edad)
}
```

Crear desde pares:

```js
const m = new Map([['a', 1], ['b', 2]])
Object.fromEntries(m) // { a: 1, b: 2 }
```

## ¿Map u objeto?

| | Objeto `{}` | `Map` |
|---|---|---|
| Claves | strings (y symbols) | cualquier valor, incluso objetos |
| Orden | casi siempre de inserción | siempre de inserción |
| Tamaño | `Object.keys(o).length` | `m.size` |
| Añadir/quitar a menudo | regular | optimizado |
| JSON | directo | hay que convertir |

Usa **objetos** para datos con forma fija (un usuario). Usa **Map** cuando las claves son dinámicas (conteos, cachés, índices por id).

## Ejemplo: contar palabras

```js
const conteo = new Map()
for (const palabra of texto.split(' ')) {
  conteo.set(palabra, (conteo.get(palabra) ?? 0) + 1)
}
```

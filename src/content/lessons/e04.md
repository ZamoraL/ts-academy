## Clases genéricas

```ts
class Pila<T> {
  private items: T[] = []

  push(item: T): void {
    this.items.push(item)
  }

  pop(): T | undefined {
    return this.items.pop()
  }

  get tamaño(): number {
    return this.items.length
  }
}

const nums = new Pila<number>()
nums.push(1)
nums.push('dos') // Error
const n = nums.pop() // number | undefined
```

El parámetro de tipo se fija al crear la instancia. Si el constructor recibe un valor de tipo `T`, TS lo infiere:

```ts
class Caja<T> {
  constructor(public valor: T) {}
}
new Caja('hola') // Caja<string>
```

Los miembros `static` **no** pueden usar el `T` de la clase (pertenecen a la clase, no a una instancia concreta).

## Valores por defecto

Un parámetro de tipo puede tener un defecto, como los parámetros de funciones:

```ts
interface Evento<T = undefined> {
  tipo: string
  payload: T
}

const a: Evento = { tipo: 'cerrar', payload: undefined }
const b: Evento<{ id: number }> = { tipo: 'abrir', payload: { id: 1 } }
```

```ts
type Respuesta<T = unknown> = { ok: boolean; datos: T }
```

Reglas:

- Los parámetros con defecto van **después** de los obligatorios.
- El defecto debe cumplir la restricción: `<T extends string = 'a'>`.

## Ejemplo: un caché genérico

```ts
class Cache<K, V> {
  private datos = new Map<K, { valor: V; expira: number }>()

  constructor(private ttlMs: number) {}

  set(clave: K, valor: V) {
    this.datos.set(clave, { valor, expira: Date.now() + this.ttlMs })
  }

  get(clave: K): V | undefined {
    const e = this.datos.get(clave)
    if (!e || e.expira < Date.now()) return undefined
    return e.valor
  }
}

const usuarios = new Cache<number, Usuario>(60_000)
```

Una sola implementación, segura para cualquier combinación de tipos.

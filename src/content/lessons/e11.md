Un **mapped type** crea un tipo nuevo recorriendo las claves de otro.

## Sintaxis

```ts
type Opciones<T> = {
  [K in keyof T]: boolean
}

type Features = { modoOscuro: () => void; perfil: () => void }
type FeatureFlags = Opciones<Features>
// { modoOscuro: boolean; perfil: boolean }
```

`[K in keyof T]` se lee "para cada clave K de T". Es como un `for` sobre las claves, pero a nivel de tipos.

## Conservar el tipo original: T[K]

```ts
type Copia<T> = {
  [K in keyof T]: T[K]
}
```

Y a partir de ahí, transformar:

```ts
type Nullable<T> = { [K in keyof T]: T[K] | null }
type Promesas<T> = { [K in keyof T]: Promise<T[K]> }
type Getters<T> = { [K in keyof T]: () => T[K] }
```

## Modificadores: ? y readonly

Puedes **añadir** (`+`, el defecto) o **quitar** (`-`) los modificadores `?` y `readonly`:

```ts
type Opcional<T> = { [K in keyof T]?: T[K] }
type SoloLectura<T> = { readonly [K in keyof T]: T[K] }

type Requerido<T> = { [K in keyof T]-?: T[K] }
type Mutable<T> = { -readonly [K in keyof T]: T[K] }
```

```ts
type Cuenta = { readonly id: string; nombre?: string }
type M = Mutable<Cuenta>   // { id: string; nombre?: string }
type R = Requerido<Cuenta> // { readonly id: string; nombre: string }
```

¿Te suenan? `Partial`, `Required` y `Readonly` de la librería estándar están definidos exactamente así.

## Sobre una unión de claves

No tiene que ser `keyof T`: cualquier unión de strings sirve.

```ts
type Idiomas = 'es' | 'en' | 'fr'
type Traducciones = { [L in Idiomas]: string }
// { es: string; en: string; fr: string }
```

Que es lo que hace `Record<Idiomas, string>`.

## Homomórficos

Un mapped type sobre `keyof T` es *homomórfico*: conserva automáticamente los `?` y `readonly` originales.

```ts
type Copia<T> = { [K in keyof T]: T[K] }
type C = Copia<{ readonly a: 1; b?: 2 }> // { readonly a: 1; b?: 2 }
```

## Combinado con conditional types

```ts
type SoloStrings<T> = {
  [K in keyof T]: T[K] extends string ? T[K] : never
}
```

En la próxima unidad verás cómo **eliminar** claves en vez de dejarlas como `never`.

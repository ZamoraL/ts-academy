**Destructuring** extrae valores de objetos y arrays en variables, en una sola línea.

## Objetos

```js
const usuario = { nombre: 'Ada', edad: 36, ciudad: 'Londres' }

// sin destructuring
const nombre = usuario.nombre
const edad = usuario.edad

// con destructuring
const { nombre, edad } = usuario
```

Las variables toman el valor de la propiedad **con el mismo nombre**.

### Renombrar y valores por defecto

```js
const { nombre: n, pais = 'desconocido' } = usuario
// n = 'Ada', pais = 'desconocido' (no existía)
```

### Anidado

```js
const pedido = { id: 7, cliente: { email: 'a@x.com' } }
const { cliente: { email } } = pedido // email = 'a@x.com'
```

## Arrays

Aquí importa la **posición**, no el nombre:

```js
const colores = ['rojo', 'verde', 'azul']
const [primero, segundo] = colores // 'rojo', 'verde'
const [, , tercero] = colores      // salta posiciones → 'azul'
```

### Intercambiar variables

```js
let a = 1
let b = 2
;[a, b] = [b, a] // a = 2, b = 1
```

## En parámetros de funciones

El uso más común, sobre todo en React:

```js
function presentar({ nombre, edad }) {
  return `${nombre} (${edad})`
}
presentar(usuario)
```

```js
const puntos = [[1, 2], [3, 4]]
puntos.map(([x, y]) => x + y) // [3, 7]
```

Y con `Object.entries`:

```js
for (const [clave, valor] of Object.entries(usuario)) { ... }
```

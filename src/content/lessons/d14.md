## Tuplas

Una **tupla** es un array con **longitud fija** y un tipo **por posición**:

```ts
type Par = [string, number]

const p: Par = ['edad', 36]
const a = p[0] // string
const b = p[1] // number
p[2]
// Error: Tuple type '[string, number]' of length '2' has no element at index '2'.
```

Se desestructuran como arrays:

```ts
const [clave, valor] = p
```

### Para qué

Devolver varios valores de una función sin crear un objeto:

```ts
function minMax(nums: number[]): [number, number] {
  return [Math.min(...nums), Math.max(...nums)]
}
const [min, max] = minMax([3, 1, 4])
```

Así funciona `useState` de React: `const [valor, setValor] = useState(0)`.

`Object.entries` devuelve `[string, T][]`: un array de tuplas.

### Opcionales y rest

```ts
type Punto = [number, number, number?]          // z opcional
type ConNombre = [string, ...number[]]           // un string y luego números
```

### Con nombre (solo documentación)

```ts
type Rango = [inicio: number, fin: number]
```

## Inferencia: cuidado

TS infiere arrays, **no** tuplas:

```ts
const x = ['a', 1] // (string | number)[]
const y = ['a', 1] as const // readonly ['a', 1]
```

Si quieres una tupla, anótala o usa `as const`.

## Arrays readonly

`readonly string[]` (o `ReadonlyArray<string>`) es un array sin métodos que lo modifiquen:

```ts
function sumar(nums: readonly number[]) {
  nums.push(1)
  // Error: Property 'push' does not exist on type 'readonly number[]'.
  return nums.reduce((a, n) => a + n, 0) // ✓ leer está bien
}
```

### Por qué usarlos en parámetros

Un parámetro `readonly number[]` **acepta** arrays normales y readonly. Un `number[]` **no acepta** readonly:

```ts
const fijos = [1, 2, 3] as const

function a(nums: number[]) {}
function b(nums: readonly number[]) {}

a(fijos) // Error: The type 'readonly [1, 2, 3]' is 'readonly' and cannot be assigned to the mutable type 'number[]'.
b(fijos) // ✓
```

Además documenta que tu función **no modifica** el array. Buena costumbre para funciones que solo leen.

### Tuplas readonly

```ts
function distancia([x, y]: readonly [number, number]) { ... }
```

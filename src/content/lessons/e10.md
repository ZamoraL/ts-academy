Cuando un conditional type recibe una **unión** en un parámetro genérico "desnudo", se aplica **a cada miembro por separado** y los resultados se unen. Esto se llama *distribución*.

```ts
type ArrayDe<T> = T extends any ? T[] : never

type A = ArrayDe<string | number>
// = ArrayDe<string> | ArrayDe<number>
// = string[] | number[]
```

Fíjate: no `(string | number)[]`, sino `string[] | number[]`.

## Por qué funciona Exclude

```ts
type Exclude<T, U> = T extends U ? never : T

type R = Exclude<'a' | 'b' | 'c', 'a'>
// = ('a' extends 'a' ? never : 'a')
//  | ('b' extends 'a' ? never : 'b')
//  | ('c' extends 'a' ? never : 'c')
// = never | 'b' | 'c'
// = 'b' | 'c'
```

`never` desaparece de las uniones. Por eso devolver `never` es la forma de **filtrar** miembros.

```ts
type Filtrar<T, U> = T extends U ? T : never // = Extract

type Primitivos = Filtrar<string | number | (() => void) | { a: 1 }, string | number>
// string | number
```

## Cuándo se distribuye

Solo si el tipo a la izquierda de `extends` es **el parámetro genérico tal cual**:

```ts
type D<T> = T extends any ? T[] : never       // distribuye
type N<T> = [T] extends [any] ? T[] : never   // NO distribuye
```

```ts
type A = D<string | number> // string[] | number[]
type B = N<string | number> // (string | number)[]
```

Envolver en una tupla `[T]` es el truco estándar para **evitar** la distribución.

## El caso de never

`never` es una unión **vacía**. Distribuir sobre "nada" da "nada":

```ts
type EsNever<T> = T extends never ? true : false
type X = EsNever<never> // never 😕 (no true)

type EsNever2<T> = [T] extends [never] ? true : false
type Y = EsNever2<never> // true ✓
```

## boolean también es una unión

```ts
type Arr<T> = T extends any ? T[] : never
type B = Arr<boolean> // false[] | true[]
```

Porque `boolean` = `true | false`. Si te sorprende un resultado así, piensa en la distribución.

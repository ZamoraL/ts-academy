Un **union type** describe un valor que puede ser **uno de varios tipos**. Se escribe con `|`.

```ts
function imprimirId(id: number | string) {
  console.log('Tu id es: ' + id)
}

imprimirId(101)     // ✓
imprimirId('202')   // ✓
imprimirId({ id: 1 })
// Error: Argument of type '{ id: number; }' is not assignable to parameter of type 'string | number'.
```

## Usar un valor de tipo unión

TS solo te deja hacer lo que es válido para **todos** los miembros de la unión:

```ts
function imprimirId(id: number | string) {
  console.log(id.toUpperCase())
  // Error: Property 'toUpperCase' does not exist on type 'string | number'.
  //   Property 'toUpperCase' does not exist on type 'number'.
}
```

La solución es **estrechar** (narrowing) la unión con una comprobación:

```ts
function imprimirId(id: number | string) {
  if (typeof id === 'string') {
    console.log(id.toUpperCase()) // id: string
  } else {
    console.log(id.toFixed(2))    // id: number
  }
}
```

TS sigue tus `if` y sabe qué tipo hay en cada rama. Esto es tan importante que tiene un bloque entero (D).

### Arrays

```ts
function saludar(x: string[] | string) {
  if (Array.isArray(x)) {
    console.log('Hola, ' + x.join(' y ')) // x: string[]
  } else {
    console.log('Hola, ' + x)             // x: string
  }
}
```

### Lo que tienen en común sí se puede usar directamente

```ts
function primeros3(x: number[] | string) {
  return x.slice(0, 3) // arrays y strings tienen slice
}
```

## Unión de arrays vs array de unión

```ts
let a: string[] | number[]   // todo strings, o todo números
let b: (string | number)[]   // mezclados
```

## Uniones con undefined

Muy comunes. `string | undefined` es "un string o nada":

```ts
function buscarNombre(id: number): string | undefined {
  return id === 1 ? 'Ada' : undefined
}

const n = buscarNombre(2)
n.length         // Error: 'n' is possibly 'undefined'.
n?.length        // ✓
```

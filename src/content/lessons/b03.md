Dos operadores para trabajar con valores que pueden ser `null` o `undefined`.

## El problema

```js
const usuario = { nombre: 'Ana' } // sin dirección
usuario.direccion.ciudad // TypeError: Cannot read properties of undefined
```

## Optional chaining `?.`

Si lo de la izquierda es `null` o `undefined`, **se detiene y devuelve `undefined`** en lugar de lanzar un error:

```js
usuario.direccion?.ciudad // undefined
usuario?.nombre           // 'Ana'
```

También funciona con índices y llamadas:

```js
lista?.[0]
callback?.()  // llama solo si callback existe
```

## Nullish coalescing `??`

Devuelve el lado derecho **solo si** el izquierdo es `null` o `undefined`:

```js
const ciudad = usuario.direccion?.ciudad ?? 'Sin ciudad'
```

## `??` vs `||`

`||` reacciona a **cualquier falsy**; `??` solo a `null`/`undefined`:

```js
const volumen = 0
volumen || 50 // 50  ❌ el 0 era un valor válido
volumen ?? 50 // 0   ✅

const nombre = ''
nombre || 'Anónimo' // 'Anónimo'
nombre ?? 'Anónimo' // ''
```

**Regla:** para valores por defecto, prefiere `??`. Usa `||` solo si de verdad quieres reemplazar `0`, `''` y `false`.

## Asignación

```js
config.timeout ??= 3000 // asigna solo si es null/undefined
```

> TypeScript hace estos operadores todavía más útiles: te dice **exactamente** dónde un valor puede ser `undefined`, para que no se te olvide el `?.`.

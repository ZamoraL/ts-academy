## Props con una interfaz

```tsx
interface AvatarProps {
  nombre: string
  tamaño?: number
}

function Avatar({ nombre, tamaño = 48 }: AvatarProps) {
  return <img alt={nombre} width={tamaño} height={tamaño} />
}
```

Igual que tipar cualquier parámetro desestructurado. Convención: `NombreComponenteProps`.

Para componentes pequeños, inline también vale:

```tsx
function Saludo({ nombre }: { nombre: string }) { ... }
```

## children: ReactNode

`ReactNode` es "cualquier cosa que React puede renderizar": JSX, strings, números, `null`, arrays de esas cosas...

```tsx
import type { ReactNode } from 'react'

interface TarjetaProps {
  titulo: string
  children: ReactNode
}

function Tarjeta({ titulo, children }: TarjetaProps) {
  return (
    <section>
      <h2>{titulo}</h2>
      {children}
    </section>
  )
}
```

Si `children` es opcional: `children?: ReactNode`.

## Funciones como props

```tsx
interface BotonProps {
  children: ReactNode
  onClick: () => void
  variante?: 'primario' | 'secundario'
}
```

Fíjate en `variante`: una unión de literales hace que TS rechace valores inválidos y el editor autocomplete las opciones. Es uno de los mayores beneficios de TS en componentes.

## Extender props de elementos HTML

Si tu componente envuelve un `<button>`, puedes aceptar todas sus props nativas:

```tsx
import type { ComponentProps } from 'react'

interface BotonProps extends ComponentProps<'button'> {
  variante?: 'primario' | 'secundario'
}

function Boton({ variante = 'primario', className, ...resto }: BotonProps) {
  return <button className={`btn btn-${variante} ${className ?? ''}`} {...resto} />
}

<Boton type="submit" disabled onClick={...}>Guardar</Boton> // todo tipado
```

`ComponentProps<'input'>`, `ComponentProps<'a'>`... funcionan igual. También puedes obtener las props de otro componente: `ComponentProps<typeof Avatar>`.

## Props que dependen de otras

Con una unión discriminada:

```tsx
type AvisoProps =
  | { tipo: 'exito'; mensaje: string }
  | { tipo: 'error'; mensaje: string; reintentar: () => void }

<Aviso tipo="error" mensaje="Falló" />
// Error: Property 'reintentar' is missing...
```

## Tipo de retorno

No hace falta anotarlo: TS infiere `JSX.Element` (o `ReactNode`). Evita `React.FC`: era popular, pero hoy se recomienda tipar las props directamente.

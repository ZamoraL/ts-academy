Es hora de juntar todo lo del bloque A en un pequeño programa: **una lista de tareas** que funciona en la consola.

## Qué vas a construir

Un conjunto de funciones que manejan un array de tareas. Cada tarea es un objeto:

```js
{ id: 1, titulo: 'Comprar pan', hecha: false }
```

En esta parte implementarás las operaciones básicas:

1. `crearTarea(id, titulo)`: crea el objeto de una tarea nueva.
2. `agregar(tareas, titulo)`: devuelve un array **nuevo** con la tarea añadida (el id es el mayor existente + 1).
3. `completar(tareas, id)`: devuelve un array nuevo donde esa tarea tiene `hecha: true`.
4. `eliminar(tareas, id)`: devuelve un array nuevo sin esa tarea.
5. `formatear(tareas)`: devuelve un string con una línea por tarea: `[x] Comprar pan` o `[ ] Comprar pan`.

## Regla importante: no mutar

Ninguna función debe modificar el array ni los objetos que recibe. Siempre devuelve **nuevos**. Para copiar un objeto cambiando una propiedad, por ahora:

```js
const copia = Object.assign({}, tarea, { hecha: true })
```

(En el bloque B verás una sintaxis más corta: `{ ...tarea, hecha: true }`.)

## Pistas generales

- `agregar`: el id nuevo puede calcularse con `reduce` buscando el máximo, o `0` si la lista está vacía.
- `completar`: `map` devolviendo la tarea modificada solo si coincide el id.
- `eliminar`: `filter`.
- `formatear`: `map` + `join('\n')`.

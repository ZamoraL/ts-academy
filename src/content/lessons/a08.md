Un condicional ejecuta código **solo si** se cumple una condición.

## if

```js
const temperatura = 30
if (temperatura > 25) {
  console.log('Hace calor')
}
```

## if / else

```js
if (temperatura > 25) {
  console.log('Hace calor')
} else {
  console.log('No hace calor')
}
```

## else if

Las condiciones se evalúan **en orden** y solo se ejecuta la primera que se cumpla:

```js
function clasificar(nota) {
  if (nota >= 9) {
    return 'Excelente'
  } else if (nota >= 7) {
    return 'Bien'
  } else if (nota >= 5) {
    return 'Aprobado'
  } else {
    return 'Suspenso'
  }
}
```

Si pusieras `nota >= 5` primero, un 10 devolvería `'Aprobado'`. El orden importa.

## Retorno temprano

Dentro de funciones, un `return` corta la ejecución. Esto evita anidar `else`:

```js
function dividir(a, b) {
  if (b === 0) {
    return 'No se puede dividir entre 0'
  }
  return a / b
}
```

Este patrón (*guard clause*) es muy común y lo usarás mucho con TypeScript para el *narrowing*.

## Condiciones combinadas

```js
if (edad >= 18 && tieneDni) { ... }
if (esAdmin || esDueño) { ... }
if (!estaBloqueado) { ... }
```

## Aritmética

```js
5 + 2   // 7
5 - 2   // 3
5 * 2   // 10
5 / 2   // 2.5
5 % 2   // 1   (resto de la división)
5 ** 2  // 25  (potencia)
```

El operador `%` (módulo) es muy útil: `n % 2 === 0` significa "n es par".

## Precedencia

Igual que en matemáticas: primero `**`, luego `*` `/` `%`, luego `+` `-`. Usa paréntesis cuando dudes:

```js
2 + 3 * 4    // 14
(2 + 3) * 4  // 20
```

## + con strings

Si uno de los lados es un string, `+` **concatena**:

```js
'1' + 2   // '12'
1 + 2 + '3' // '33'  (primero 1 + 2 = 3, luego 3 + '3')
```

Los demás operadores intentan convertir a número: `'6' / 2` es `3`. Esta mezcla es fuente de bugs, y una de las cosas que TypeScript evita.

## Asignación compuesta

```js
let x = 10
x += 5   // x = x + 5  → 15
x -= 3   // 12
x *= 2   // 24
x /= 4   // 6
x++      // 7
x--      // 6
```

## Decimales

```js
0.1 + 0.2 // 0.30000000000000004
```

Los números decimales se guardan en binario y algunos no son exactos. Para mostrar dinero, redondea: `(0.1 + 0.2).toFixed(2)` → `'0.30'`.

## Parámetros opcionales

Un `?` marca el parámetro como opcional. Su tipo incluye `undefined`:

```ts
function formatear(n: number, decimales?: number) {
  // decimales: number | undefined
  return n.toFixed(decimales ?? 2)
}

formatear(3.14159)    // '3.14'
formatear(3.14159, 4) // '3.1416'
```

Los opcionales van **después** de los obligatorios.

### Con valor por defecto

Más limpio cuando hay un defecto claro. TS infiere el tipo del defecto:

```ts
function formatear(n: number, decimales = 2) {
  // decimales: number
  return n.toFixed(decimales)
}
```

## Opcionales en callbacks: un error común

Al escribir el tipo de un callback, **no** marques parámetros como opcionales "por si el usuario no los usa":

```ts
// ❌
function miForEach(arr: number[], cb: (valor: number, indice?: number) => void) {}

// ✅ quien implementa el callback puede ignorar el índice igual
function miForEach(arr: number[], cb: (valor: number, indice: number) => void) {}
```

En TS, una función con **menos** parámetros siempre se puede pasar donde se esperan más. Marcar `indice?` obliga a quien lo usa a comprobar `undefined`.

## Parámetros rest

Agrupan un número variable de argumentos en un array. Su tipo es un array:

```ts
function multiplicar(factor: number, ...nums: number[]): number[] {
  return nums.map((n) => n * factor)
}

multiplicar(10, 1, 2, 3) // [10, 20, 30]
```

## Argumentos spread

Al revés: expandir un array en argumentos.

```ts
const nums = [1, 2, 3]
Math.max(...nums) // ✓
```

Con funciones que esperan un número **fijo** de parámetros, TS necesita saber la longitud:

```ts
const args = [8, 5]
Math.atan2(...args)
// Error: A spread argument must either have a tuple type or be passed to a rest parameter.

const args2 = [8, 5] as const // readonly [8, 5]: una tupla
Math.atan2(...args2) // ✓
```

## Desestructurar parámetros

```ts
function sumar({ a, b, c }: { a: number; b: number; c: number }) {
  return a + b + c
}

// mejor con un tipo con nombre
type ABC = { a: number; b: number; c: number }
function sumar({ a, b, c }: ABC) { ... }
```

Esto es exactamente lo que harás con las props de React.

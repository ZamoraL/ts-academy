A veces **tú sabes** algo sobre un tipo que TS no puede saber. Las *assertions* le dicen "confía en mí".

## as

```ts
const canvas = document.getElementById('lienzo') as HTMLCanvasElement
canvas.getContext('2d') // ✓ HTMLCanvasElement tiene getContext
```

`getElementById` devuelve `HTMLElement | null`. Tú sabes que ese id es un `<canvas>` y existe; TS no.

## Una assertion no cambia nada en runtime

Se borra al compilar. Si te equivocas, TS no te avisa y el error aparece al ejecutar:

```ts
const x = 'hola' as unknown as number
x.toFixed(2) // TS feliz, crash en runtime: x.toFixed is not a function
```

**Una assertion es una promesa que haces tú, no una comprobación.**

## Límites

TS solo permite assertions a tipos "más específicos" o "más generales", no a tipos sin relación:

```ts
const x = 'hola' as number
// Error: Conversion of type 'string' to type 'number' may be a mistake...
```

(El truco `as unknown as T` se salta esto; si lo necesitas, probablemente algo está mal.)

## Non-null assertion: `!`

Un `!` después de una expresión dice "esto no es `null` ni `undefined`":

```ts
const app = document.getElementById('app')! // HTMLElement, sin null
```

Mismo riesgo: si resulta ser `null`, crash.

## ¿Cuándo usarlas?

Casi nunca. Antes, intenta:

```ts
// ❌ assertion
const usuario = usuarios.find((u) => u.id === id)!

// ✅ comprobación
const usuario = usuarios.find((u) => u.id === id)
if (!usuario) throw new Error(`Usuario ${id} no encontrado`)
```

La comprobación te da un error claro y TS estrecha el tipo igual. Usos razonables de `as`:

- Elementos del DOM que sabes que existen (con cuidado).
- Tests.
- `as const` (que no es una assertion peligrosa: solo hace el tipo más estrecho).

## satisfies

Una alternativa más segura: comprueba que un valor cumple un tipo **sin cambiar** el tipo inferido.

```ts
type Colores = Record<string, string>

const tema = {
  fondo: '#000',
  texto: '#fff',
} satisfies Colores

tema.fondo   // ✓ TS sabe que existe
tema.borde   // Error: Property 'borde' does not exist
```

Con `: Colores` perderías el conocimiento de qué claves exactas tiene.

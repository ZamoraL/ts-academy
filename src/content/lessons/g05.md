Mostrar cosas distintas según una condición. Como JSX no admite `if` dentro de las llaves, hay varias técnicas.

## if con return temprano

Fuera del JSX, JavaScript normal:

```jsx
function Item({ nombre, empacado }) {
  if (empacado) {
    return <li>{nombre} ✅</li>
  }
  return <li>{nombre}</li>
}
```

## Ternario

Dentro del JSX:

```jsx
<li>{empacado ? <del>{nombre}</del> : nombre}</li>
```

## && para "mostrar o nada"

```jsx
<li>
  {nombre} {empacado && '✅'}
</li>
```

Si `empacado` es `false`, la expresión vale `false`, que React no muestra.

### Cuidado con el 0

```jsx
{mensajes.length && <p>Tienes mensajes</p>}
```

Si `length` es `0`, la expresión vale `0`... y React **sí** muestra el `0`. Usa una comparación:

```jsx
{mensajes.length > 0 && <p>Tienes mensajes</p>}
```

## Devolver null

Un componente puede no mostrar nada:

```jsx
function Aviso({ mensaje }) {
  if (!mensaje) return null
  return <div className="aviso">{mensaje}</div>
}
```

## Con variables

Para lógica más compleja, prepara el contenido antes del `return`:

```jsx
function Estado({ estado }) {
  let contenido
  if (estado === 'cargando') contenido = <p>Cargando…</p>
  else if (estado === 'error') contenido = <p>Algo falló</p>
  else contenido = <p>Listo</p>

  return <div className="estado">{contenido}</div>
}
```

## ¿Cuál uso?

- Componente entero distinto: `if` + `return`.
- Pequeña variación dentro del JSX: ternario o `&&`.
- Muchas ramas: variable o un objeto de mapeo.

```jsx
const ICONOS = { ok: '✅', error: '❌', aviso: '⚠️' }
<span>{ICONOS[tipo]}</span>
```

Estos tres métodos reciben una función y **no modifican** el array original. Son el pan de cada día en JavaScript y React.

## map: transformar cada elemento

Devuelve un array nuevo **del mismo tamaño**:

```js
const precios = [10, 20, 30]
const conIva = precios.map((p) => p * 1.16)  // [11.6, 23.2, 34.8]

const nombres = ['ana', 'luis']
const mayus = nombres.map((n) => n.toUpperCase()) // ['ANA', 'LUIS']
```

La función recibe `(elemento, indice, array)`; casi siempre solo usarás el primero.

## filter: quedarse con algunos

Devuelve un array nuevo con los elementos para los que la función devuelve `true`:

```js
const nums = [1, 2, 3, 4, 5, 6]
const pares = nums.filter((n) => n % 2 === 0) // [2, 4, 6]
```

## find: el primero que cumpla

Devuelve **el elemento** (no un array), o `undefined` si ninguno cumple:

```js
nums.find((n) => n > 3)   // 4
nums.find((n) => n > 10)  // undefined
nums.findIndex((n) => n > 3) // 3
```

## Encadenar

Como `map` y `filter` devuelven arrays, puedes encadenarlos:

```js
const total = [5, 12, 8, 20]
  .filter((n) => n > 6)  // [12, 8, 20]
  .map((n) => n * 2)     // [24, 16, 40]
```

## Compara con un bucle

```js
// con bucle
const pares = []
for (const n of nums) {
  if (n % 2 === 0) pares.push(n)
}

// con filter
const pares = nums.filter((n) => n % 2 === 0)
```

La segunda dice **qué** quieres, no **cómo** hacerlo. Es más corta y difícil de romper.

## reduce: combinar todo en un valor

`reduce` recorre el array llevando un **acumulador**:

```js
const nums = [1, 2, 3, 4]
const suma = nums.reduce((acc, n) => acc + n, 0) // 10
```

- `acc` es el acumulador: empieza con el valor inicial (`0`).
- En cada vuelta, lo que devuelves pasa a ser el nuevo `acc`.

Paso a paso: `0 + 1 = 1` → `1 + 2 = 3` → `3 + 3 = 6` → `6 + 4 = 10`.

**Pasa siempre el valor inicial.** Sin él, `reduce` usa el primer elemento y falla con arrays vacíos.

### Otros usos

```js
// máximo
nums.reduce((max, n) => (n > max ? n : max), -Infinity) // 4

// contar ocurrencias en un objeto
const votos = ['a', 'b', 'a']
votos.reduce((conteo, v) => {
  conteo[v] = (conteo[v] || 0) + 1
  return conteo
}, {}) // { a: 2, b: 1 }
```

Si un `reduce` se vuelve difícil de leer, un `for...of` es perfectamente válido.

## some y every

Devuelven `boolean`:

```js
const edades = [15, 22, 30]
edades.some((e) => e < 18)   // true: al menos uno
edades.every((e) => e >= 18) // false: no todos
```

Se detienen en cuanto conocen la respuesta.

## Resumen de métodos de array

| Quiero... | Método | Devuelve |
|---|---|---|
| Transformar cada uno | `map` | array mismo tamaño |
| Quedarme con algunos | `filter` | array más pequeño |
| Encontrar uno | `find` | elemento o `undefined` |
| ¿Alguno cumple? | `some` | boolean |
| ¿Todos cumplen? | `every` | boolean |
| Combinar en un valor | `reduce` | cualquier cosa |

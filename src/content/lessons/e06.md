En JavaScript, `typeof` devuelve un string en runtime. TypeScript añade un **`typeof` en posición de tipo**, que obtiene el **tipo** de una variable.

```ts
const s = 'hola'
let n: typeof s // "hola"
```

## Para qué sirve: una sola fuente de verdad

En lugar de escribir un tipo y luego un valor que lo cumple, escribe el valor y **deriva** el tipo:

```ts
const configPorDefecto = {
  tema: 'oscuro',
  idioma: 'es',
  notificaciones: true,
}

type Config = typeof configPorDefecto
// { tema: string; idioma: string; notificaciones: boolean }
```

Si añades una propiedad al objeto, el tipo se actualiza solo.

## Con funciones y ReturnType

`typeof` sobre una función da su tipo de función. Combinado con el utility type `ReturnType`:

```ts
function crearUsuario(nombre: string) {
  return { nombre, creado: new Date(), activo: true }
}

type Usuario = ReturnType<typeof crearUsuario>
// { nombre: string; creado: Date; activo: boolean }
```

Ojo: `ReturnType<crearUsuario>` es un error, porque `crearUsuario` es un **valor**, no un tipo. Hace falta `typeof`.

## Con as const

```ts
const ROLES = ['admin', 'editor', 'lector'] as const
type Rol = (typeof ROLES)[number] // 'admin' | 'editor' | 'lector'

const HTTP = { ok: 200, noEncontrado: 404 } as const
type CodigoHttp = (typeof HTTP)[keyof typeof HTTP] // 200 | 404
```

Patrón muy útil: tienes la lista en runtime (para iterarla, validar...) y el tipo en compilación, sin duplicar.

## Limitación

Solo funciona con **identificadores** (nombres de variables y sus propiedades), no con expresiones:

```ts
type T = typeof crearUsuario('x') // Error
```

## typeof en tipo vs en valor

```ts
const x = 5
const a = typeof x  // en valor: 'number' (string en runtime)
type B = typeof x   // en tipo: number
```

El contexto decide cuál es.

En la parte 2 añadirás **consultas y estadísticas** a tu lista de tareas. Ahora cada tarea tiene también prioridad:

```js
{ id: 1, titulo: 'Comprar pan', hecha: false, prioridad: 'alta' }
```

Las prioridades posibles son `'alta'`, `'media'` y `'baja'`.

## Funciones a implementar

1. `pendientes(tareas)`: solo las no hechas.
2. `buscar(tareas, texto)`: las que contienen `texto` en el título, **sin importar mayúsculas**.
3. `porPrioridad(tareas)`: ordenadas alta → media → baja, sin modificar el original.
4. `estadisticas(tareas)`: un objeto `{ total, hechas, pendientes, porcentaje }`, donde `porcentaje` es el % de hechas redondeado a entero (`0` si no hay tareas).
5. `validarTitulo(titulo)`: lanza un `Error` con mensaje `'El título no puede estar vacío'` si el título (sin espacios alrededor) está vacío; si no, devuelve el título sin espacios alrededor.

## Pistas generales

- Para ordenar por prioridad, crea un objeto de pesos: `{ alta: 0, media: 1, baja: 2 }` y compara `pesos[a.prioridad] - pesos[b.prioridad]`.
- `Math.round` redondea.
- `trim()` quita espacios alrededor.

Cuando termines, habrás usado casi todo lo del bloque: funciones, condicionales, arrays, objetos, métodos de array y errores. 🎉

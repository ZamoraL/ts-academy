Cuatro tipos que aparecen mucho en firmas de funciones.

## void

El retorno de funciones que **no devuelven un valor útil**:

```ts
function registrar(mensaje: string): void {
  console.log(mensaje)
}
```

`void` no es lo mismo que `undefined`. Como viste con callbacks, una función tipada `() => void` puede devolver algo y se ignora:

```ts
type Callback = () => void
const f: Callback = () => 42 // ✓, el 42 se ignora
```

Pero si **anotas** una declaración de función con `: void`, no puede devolver un valor:

```ts
function g(): void {
  return 42 // Error
}
```

## object

Cualquier valor que **no sea primitivo** (objetos, arrays, funciones):

```ts
function claves(o: object) {
  return Object.keys(o)
}
claves({ a: 1 }) // ✓
claves([1])      // ✓
claves('hola')   // Error
```

No confundir con `Object` (mayúscula) ni con `{}`, que aceptan casi todo, incluidos primitivos. Usa `object` minúscula.

## unknown

Ya lo conoces: "cualquier valor, pero compruébalo antes de usarlo". Ideal para parámetros que aceptan cualquier cosa:

```ts
function aTexto(valor: unknown): string {
  if (typeof valor === 'string') return valor
  if (valor instanceof Error) return valor.message
  return JSON.stringify(valor)
}
```

## never

Para funciones que **nunca devuelven**: siempre lanzan o tienen un bucle infinito.

```ts
function fallar(mensaje: string): never {
  throw new Error(mensaje)
}

function bucleEterno(): never {
  while (true) {}
}
```

Y TS aprovecha esto en el flujo de control:

```ts
function dividir(a: number, b: number) {
  if (b === 0) fallar('División entre 0')
  return a / b // TS sabe que si b fuera 0 no llegaría aquí
}
```

## Function

El tipo global `Function` describe "cualquier función", pero llamarla devuelve `any`. Evítalo: escribe el tipo concreto, como `() => void` o `(...args: unknown[]) => unknown`.

## Resumen

| Tipo | Significa |
|---|---|
| `void` | no devuelve nada útil |
| `object` | cualquier no primitivo |
| `unknown` | cualquier cosa, sin usarla sin comprobar |
| `never` | nunca devuelve / no puede existir |

Un **indexed access type** obtiene el tipo de una propiedad de otro tipo, con la misma sintaxis de corchetes que usas en valores.

```ts
type Persona = { nombre: string; edad: number; activo: boolean }

type Edad = Persona['edad'] // number
```

## Con uniones de claves

```ts
type A = Persona['nombre' | 'edad'] // string | number
type B = Persona[keyof Persona]     // string | number | boolean
```

## Anidado

```ts
type Pedido = {
  cliente: { direccion: { ciudad: string } }
  items: { sku: string; cantidad: number }[]
}

type Ciudad = Pedido['cliente']['direccion']['ciudad'] // string
type Item = Pedido['items'][number]                    // { sku: string; cantidad: number }
```

## [number]: el tipo de los elementos

Para arrays, indexar con `number` da el tipo de sus elementos:

```ts
const usuarios = [
  { nombre: 'Ana', edad: 30 },
  { nombre: 'Luis', edad: 25 },
]
type Usuario = (typeof usuarios)[number] // { nombre: string; edad: number }
```

Con tuplas, puedes indexar por posición:

```ts
type Par = [string, number]
type Primero = Par[0] // string
```

## Solo tipos, no valores

```ts
const clave = 'edad'
type E = Persona[clave]
// Error: 'clave' refers to a value, but is being used as a type here.

type Clave = 'edad'
type E2 = Persona[Clave] // ✓
```

## Combinado con genéricos

Aquí está la magia de `obtener`:

```ts
function obtener<T, K extends keyof T>(obj: T, clave: K): T[K] {
  return obj[clave]
}
```

`T[K]` es "el tipo de la propiedad K de T", calculado en cada llamada.

## Por qué es útil

Cuando trabajas con tipos que no controlas (respuestas de APIs generadas, tipos de librerías), puedes extraer piezas sin redefinirlas:

```ts
type Props = React.ComponentProps<'button'>
type OnClick = Props['onClick']
```

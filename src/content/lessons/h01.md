Ya sabes TypeScript y ya sabes React. En este bloque los juntas: es como se escribe la mayoría del React profesional hoy.

## Crear un proyecto

```bash
npm create vite@latest mi-app -- --template react-ts
cd mi-app
npm install
npm run dev
```

La plantilla `react-ts` ya trae todo configurado:

- `tsconfig.json` con `jsx: "react-jsx"`, `strict`, `moduleResolution: "bundler"`.
- `@types/react` y `@types/react-dom`: los tipos de React.
- Archivos `.tsx` en vez de `.jsx`.

Esta misma app se creó exactamente así.

## .ts vs .tsx

- `.tsx`: archivos con JSX (componentes).
- `.ts`: archivos sin JSX (utilidades, tipos, lógica).

En un `.tsx`, la sintaxis `<T>valor` de assertion no se puede usar (choca con JSX): usa `valor as T`.

## Lo que TypeScript te da en React

```tsx
<Avatar nombre="Ada" tamano="grande" />
// Error: Type 'string' is not assignable to type 'number'.

<Boton onClik={...} />
// Error: Property 'onClik' does not exist on type 'BotonProps'. Did you mean 'onClick'?
```

- Props comprobadas en cada uso.
- Autocompletado de props, eventos y atributos HTML.
- Refactors seguros: renombra una prop y TS te muestra todos los sitios afectados.
- Estado y reducers sin estados imposibles.

## Tipos que vienen de React

Todo está en el paquete `react`:

```tsx
import type { ReactNode, ChangeEvent, FormEvent, ComponentProps } from 'react'
```

Los irás viendo unidad a unidad. La [guía oficial de TypeScript en react.dev](https://es.react.dev/learn/typescript) y la [React TypeScript Cheatsheet](https://react-typescript-cheatsheet.netlify.app) son las mejores referencias.

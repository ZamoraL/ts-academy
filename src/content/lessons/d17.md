## implements

Una clase puede declarar que **cumple** una interfaz. TS comprueba que tenga todo lo que la interfaz pide:

```ts
interface Comparable {
  compararCon(otro: this): number
}

interface Serializable {
  serializar(): string
}

class Version implements Comparable, Serializable {
  constructor(readonly mayor: number, readonly menor: number) {}

  compararCon(otro: Version) {
    return this.mayor - otro.mayor || this.menor - otro.menor
  }

  serializar() {
    return `${this.mayor}.${this.menor}`
  }
}
```

Si falta algo:

```ts
class Mala implements Serializable {}
// Error: Class 'Mala' incorrectly implements interface 'Serializable'.
//   Property 'serializar' is missing in type 'Mala' but required in type 'Serializable'.
```

`implements` **solo comprueba**: no aporta tipos a la clase. Los parámetros de los métodos siguen necesitando sus anotaciones.

## Clases abstractas

Una clase `abstract` no se puede instanciar: sirve de **base** para otras. Puede tener métodos `abstract` (sin implementación) que las subclases **deben** implementar:

```ts
abstract class Figura {
  constructor(readonly nombre: string) {}

  abstract area(): number

  describir(): string {
    return `${this.nombre}: ${this.area().toFixed(2)}`
  }
}

class Circulo extends Figura {
  constructor(private radio: number) {
    super('Círculo')
  }
  area() {
    return Math.PI * this.radio ** 2
  }
}

new Circulo(1).describir() // 'Círculo: 3.14'
new Figura('x')
// Error: Cannot create an instance of an abstract class.
```

### ¿Interfaz o clase abstracta?

- **Interfaz**: solo describe la forma. Sin código. Una clase puede implementar muchas.
- **Clase abstracta**: puede compartir código (`describir`) entre subclases. Solo se extiende una.

## static

Miembros que pertenecen a la **clase**, no a las instancias:

```ts
class Id {
  private static siguiente = 1

  static nuevo(): number {
    return Id.siguiente++
  }
}

Id.nuevo() // 1
Id.nuevo() // 2
```

Usos típicos: contadores, constantes, y **métodos fábrica**:

```ts
class Color {
  private constructor(readonly hex: string) {}

  static desdeRGB(r: number, g: number, b: number) {
    const h = (n: number) => n.toString(16).padStart(2, '0')
    return new Color(`#${h(r)}${h(g)}${h(b)}`)
  }
}

Color.desdeRGB(255, 0, 0).hex // '#ff0000'
new Color('#fff') // Error: Constructor of class 'Color' is private
```

Un constructor `private` obliga a usar las fábricas.

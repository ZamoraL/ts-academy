## switch

Cuando comparas **un mismo valor** contra muchas opciones, `switch` es más claro que muchos `else if`:

```js
function nombreDia(n) {
  switch (n) {
    case 0:
      return 'domingo'
    case 6:
      return 'sábado'
    default:
      return 'entre semana'
  }
}
```

- Compara con `===`.
- `default` se ejecuta si ningún `case` coincide.

## break y fall-through

Si no usas `return`, necesitas `break`. Sin él, la ejecución **sigue** al siguiente `case`:

```js
switch (fruta) {
  case 'manzana':
  case 'pera':
    console.log('fruta de árbol') // manzana y pera comparten código
    break
  case 'fresa':
    console.log('fruta de planta')
    break
}
```

Olvidar un `break` es un bug clásico. TypeScript tiene una opción (`noFallthroughCasesInSwitch`) que lo detecta.

## Operador ternario

Un `if/else` compacto que **devuelve un valor**:

```js
const edad = 20
const tipo = edad >= 18 ? 'adulto' : 'menor'
```

Se lee: *condición* `?` *valor si true* `:` *valor si false*.

Úsalo para decisiones simples. Si necesitas anidar ternarios, mejor usa `if`:

```js
// difícil de leer
const x = a ? (b ? 1 : 2) : 3
```
